# Data References

Expected datasets used by table/numeric/cross-source assertions.

Each reference file is the source of truth for what the UI should display. When the underlying data legitimately changes (new month, new customer, etc.), update the reference file and bump the date in its filename.

## Naming convention

`<concept>-<scope>-<YYYY-MM-DD>.{csv,json}`

Examples:
- `top-brands-default-user-2026-05-13.csv`
- `dashboard-summary-account-acme-2026-05-13.json`
