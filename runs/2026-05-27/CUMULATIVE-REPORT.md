## How to Read a Per-Ticket Report

Each per-ticket file follows the same structure: **Header** (date / account / brand / source spec) → **Result** (PASS / PARTIAL / BLOCKED with one-line reason) → **Execution** (numbered playback in spec-step order) → **Assertions** (A1..An, each PASS / NOT VERIFIED / DEFERRED with the evidence) → **Evidence** (URLs, screenshots, key numeric values) → **Notes** (quirks, spec deltas, recommended next-analyst action).
