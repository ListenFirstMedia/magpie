## Description
Verify Instagram Authorized (Private/Lifetime) data on the Brand > Content tab matches what appears for the same brand under a "Recent" tab or comparable lifetime data source.

## Preconditions
User logged in as Adam Orfei. Brand with Authorized IG (MTV `brand_id=4018` or similar) available.

## Steps
1. Navigate Brand → Content for MTV, Instagram channel, **Authorized perspective** (Rule 2: click view-toggle, verify `perspective=extended`).
2. Default In-Window data set, Last 7 Days or other supported lifetime range.
3. Capture the Sum / Avg row + first 3–5 post rows (post id + lifetime metrics: Total Impressions / Total Reach / Saves / etc.).
4. Switch to the "Recent" (sometimes labeled `recent` data set or a Lifetime-specific view) for the same brand.
5. Capture corresponding rows for the same post ids.

## Assertions
- A1 (steps 1–3): Authorized perspective indicator confirmed (URL `perspective=extended`, toggle handle right).
- A2 (step 3): Post-table populates with IG Authorized metrics; row count > 0.
- A3 (steps 3 vs 5): Per-post lifetime metric values on Content tab equal corresponding values on Recent tab to rounding.
- A4 (step 3): No "data is private — log in" placeholder rendered on Authorized rows for the test brand.
