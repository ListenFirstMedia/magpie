# QA-63603 — Settings > Tags > Content Tagged - Upload Tags

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-63603
- **Priority:** Minor
- **Ingested:** 2026-07-22 from Jira (Xray custom fields)

## Preconditions
- The user should be logged in as Adam Orfei

## Steps
1. Hover over Settings in the top nav and click Tags
2. Click on any of the available tags in the Tag column
3. Click Upload Tags
4. Click Browse and select the Downloaded CSV file
5. Click the "Upload CSV" button on the pop-up

## Assertions
3. Ensure the "Upload Tags" pop-up modal is opened
4. Ensure after selecting the CSV file the "Upload CSV" button is enabled
4. Ensure that the message displays after the CSV row: 'Click "Upload" to complete import.'
5. Ensure the pop-up Modal closes with the Sucess message: " {File Name} has been successfully uploaded.
You'll be able to download a detail log when it's ready".
