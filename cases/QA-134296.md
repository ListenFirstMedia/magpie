# QA-134296 — Brandsets → Rankings - Data Last Updated: Timestamp

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134296
- **Priority:** —
- **Description:** Verifies that the "Data Last Updated" timestamp remains consistently visible and correctly formatted across Brandsets modules, even after page refreshes and brand selection changes.

## Preconditions
- User logged in as Adam Orfei
- At least 2 brand sets accessible

## Steps
1. Navigate to Brand Sets > Rankings (brand set #1)
2. Verify `Data Last Updated (PT): …` header format and value
3. Navigate to Brand Sets > Content
4. Verify same value
5. Refresh (F5) Brand Sets > Content
6. Verify timestamp persists
7. Switch to a different brand set
8. Verify timestamp persists

## Assertions
- A1-A4: Timestamp consistent across Brand Sets sub-modules + after F5 + after brand-set switch
- A5: Format conforms to `MM-DD-YYYY HH:MM AM/PM PT`
- A6: Cross-app parity with Brand surfaces (matches QA-134271 values)
