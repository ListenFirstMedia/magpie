## Description
This test case ensures the Facebook only reels early access data set all view.

## Preconditions
User logged in as Viacom.

## Steps
1. Click Brand in Top nav and Click the Content tab.
2. Enter and Select 'MTV' in brand dropdown.
3. Click Data Set dropdown.
4. Click Data Set drop-down and select Facebook Only: Reactions Data Set.
5. Enable Only Facebook Channel.
6. Apply Filter as Publish Type: Reel.
7. Click Detail view.
8. Click Table View.

## Assertions
- A1 (step 5): Ensure the Facebook channel is only enabled and other channels are disabled by default.
- A2 (step 6a): Ensure the Reels post only displays.
- A3 (step 6b): Ensure the Aggregate table displays as Engagements, Reactions, Likes, Loves, Hahas, Wows, Sads, Angries.
- A4 (step 7): Ensure the same metrics are updated in the Detail view.
- A5 (step 8): Ensure the following columns are present in Table View: Rank, Date, Channel, Author, Type, Live, Publish Type, Paid, Sponsor, Text, Engagements, Reactions, Likes, Loves, Hahas, Wows, Sads, Angries, Others and Actions.

## Cleanup
None — read-only verification, no mutation.

## Notes
Ticket title references "jMeter" (a load-testing tool name carried over from a related perf-test naming convention in this project) — the actual steps/assertions are a standard UI data-set verification, so this is executed as a normal Playwright UI case, not a load test.
