## Preconditions
The user should be logged in as Adam Orfei.

## Steps
1. Click Brand in the top nav and Click the Paid tab
2. Click the Brand dropdown and Type and select 'Michael Kors'
3. Click the Export button
4. Select the following metrics: Facebook Engagements, Facebook Rates, Facebook Video Views, Facebook Cost and Facebook Delivery
5. Click the ok button in the export popup
6. Click the OK button in the 'Select Channels & Data Sets Export Request' popup.
7. Hover the Notification icon in the top nav
8. Click the Download file hyperlinked text in the notification.
9. Navigate to Settings > Notification

## Assertions
- A1 (7): Select Data Sets Export notification displays as follows:
  - First Row: Select Channels & Data Sets Export
  - Second Row: Mon DD, YYYY XX:YY xm (e.g., Jul 16, 2024 06:52 pm)
  - Third Row: Your Paid Export with Select Channels & Data Sets for Michael Kors from Mon. DD, YYYY to Mon. DD, YYYY is now ready. Download file.
- A2 (7): The 'Download file' text should be blue hyperlinked.
- A3 (8): The CSV file is downloaded
- A4 (9): The same 'Select Channels & Data Sets Export' notification displays
