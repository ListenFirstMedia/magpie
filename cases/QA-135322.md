# QA-135322 — Settings > Custom Metrics - Custom Metric Create Functionality - Constants

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-135322
- **Priority:** Major
- **Ingested:** 2026-07-09 from Jira (Xray custom fields)

## Preconditions
- The user should be logged in as Adam Orfei.

## Steps
1. Click 'Settings' in the top nav and select 'Custom Metrics' in the dropdown.
2. Click 'Create a Custom Metric.'
3. Enter a unique name and description (e.g., Sample Metric).
4. Click the Formula input field.
5. Select 'Constants.'
6. Type any number in the Formula input field (within -1000 to 1000).
7. Add the '+' operator.
8. Hover over 'Metrics,' then 'ListenFirst' channel, and select the 'Shares' metric.
9. Type and select the '-' operator and 'Post Likes' metric in the Formula input field.
10. Click the 'X' icon next to the last added metric.
11. Click the 'X' icon next to the last operator.
12. Click the 'Save' button.
13. Click 'OK' in the Success pop-up.

## Assertions
2a. Verify that the 'Save' button is initially disabled.
4a. Ensure the dropdown shows "Metrics", "Constants", "Parentheses" and "Operators," with "Operators" initially disabled.
5a. Ensure the input field accepts a max value of 1000 and a min value of -1000; values outside this range (e.g., 1001, -1001, 9999) are rejected.
5b. Ensure that an empty constant field is not allowed to save, the 'Save' button remains disabled.
5c. Ensure that 0 is not accepted as a valid constant value.
5d. Ensure that decimal constants (e.g., 0.5, -0.25, 99.99, -999.999) within the allowed range are accepted, and displays the value accurately without rounding or truncation.
5e. Ensure that negative numbers (e.g., -500, -1000) are accepted, the negative sign is allowed as the first character (e.g., -500).
5f. Ensure alphabetic characters (except e for scientific notation) are rejected.
5g. Ensure special characters other than - and . are rejected.
5h. Verify the 'Save' button remains disabled while the constant field contains invalid input.
6a. Verify that typing a metric name shows matching options in the dropdown.
6b. Ensure selecting a metric adds it to the formula row, displaying only the channel icon and metric name.
10a. Confirm the last metric is removed from the formula row.
11a. Ensure the last added operator is removed from the formula row.
11b. If the user removes elements such that the formula ends with a dangling operator (e.g., 5 +) or becomes empty/invalid, verify the 'Save' button is disabled.
12a. Verify that the Success pop-up displays the message 'Custom metric successfully created!'
13a. Ensure the page refreshes and shows the saved metric name on the Custom Metrics page.
13b. Verify metrics saved with negative constants, zero, and decimal values appear correctly on the Custom Metrics page.
