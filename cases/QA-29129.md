## Description

## Preconditions

## Steps
1. Hover over the Brand and Select Content from the Top Nav  
2. Add a Brand and Select the Impression dataset  
3. Enable LinkedIn Channel Only and Select last 30 Days  
4. In Each grid post Add the values of Organic Impressions, Paid Impressions  
5. In Each grid, post Add the values of Organic Reach, Paid Reach  
6. Note the values of Engagements and Impressions

## Assertions
4. Ensure the Sum of the Organic Impressions, Paid Impressions value should be equal to the Impressions Value  
5. Ensure the Sum of the Organic Reach, Promoted Reach value should be equal to Reach Value  
6. Ensure the division of Engagements and Impressions is equal to the Engagement Rate  
6. Ensure Engaged User Rate displays endash for it

Organic Reach + Promoted Reach = Reach  
Organic Impressions + Paid Impressions = Impressions  
Engagements / Impressions = Engagement Rate
