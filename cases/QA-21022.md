## Description
Data Test for Impressions — compares Reels Data Set metrics between the Dev environment (app.lfmdev.in) and the Prod environment (app.listenfirstmedia.com) for the Facebook channel.

| Days | Account | Brand |
|------|---------|-------|
| Monday | HBO MAX | HBO MAX |
| Tuesday | UCLA | UCLA |
| Wednesday | Apple Services | Apple Music |
| Thursday | Conde Nast | Vogue - US |
| Friday | Hulu | Hulu |

## Preconditions
User should follow the different login for each day per the Account/Brand table above (today is 2026-07-14, a Tuesday → use UCLA / UCLA).

## Steps
1. Navigate to https://app.lfmdev.in/ (dev).
2. Hover over Brand and Select Content from the Top Nav.
3. Add a Brand and Select Video View Dataset.
4. Enable the Facebook Channel Only.
5. Apply filter Publish Type: Reel.
6. Note the [Engagements, Video Response Rate, Video Views, Resolution] values from each post.
7. Navigate to https://app.listenfirstmedia.com/#home (prod).
8. Hover over Brand and select Content from the Top Nav.
9. Add a Brand and Select Video View Dataset.
10. Enable the Facebook Channel Only.
11. Apply filter Publish Type: Reel.
12. Note the [Engagements, Video Response Rate, Video Views, Resolution] values from each post.
13. Compare the dev and Prod posts metric values.

## Assertions
- A1 (step 13): Ensure the values of the dev posts should match with the prod posts.

## Cleanup
None — read-only verification, no mutation.

## Notes
Prod (app.listenfirstmedia.com) is a separate environment from the dev target this framework normally drives (app.lfmdev.in per config/env.md). Prod credentials/access must be confirmed before this case can run; if prod is unreachable or credentials are dev-only, this case is BLOCKED on environment access, not a product failure.
