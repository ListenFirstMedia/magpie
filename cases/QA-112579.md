# QA-112579 — Brand Content - Tag modal dragging function

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-112579
- **Priority:** Blocker
- **Description:** Ensures the tag modal dragging functionality on Brand > Content.

## Preconditions
- User logged in as Adam Orfei.

## Steps
1. Hover over the Brand dropdown and click the Content tab.
2. Click the Brand dropdown.
3. Type and select the "Michael Kors" brand.
4. Click the 'Tag' button and select the 'Bulk Tag' option.
5. In the Bulk Add Tag modal, hover over the heading section.
6. Left-click and hold the mouse, then drag the modal to the desired position on the page.
7. Scroll down and then scroll up the page.
8. Type a tag in the input field, click 'Add', then click the 'Done' button in the Bulk Add Tag modal.
9. Click the 'Tag' button again and select the 'Bulk Tag' option.

## Assertions
- A4 (step 4): "Bulk Add Tag" modal opens above the Help button at the bottom-right corner of the page.
- A5 (step 5): Cursor changes to a hand/pointer icon when hovering over the modal heading, indicating draggable.
- A6 (step 6): The modal can be dragged and repositioned to the desired location.
- A7 (step 7): The modal remains fixed in its position while the page scrolls up/down.
- A8 (step 8): The tag is successfully added and the modal closes.
- A9 (step 9): On re-open, the "Bulk Add Tag" modal consistently opens above the Help button at the bottom-right corner of the page.
