## Objective

Verify the visibility, formatting, and PT timezone accuracy of the "Data Last Updated" timestamp across various brands; and ensure that the timestamp is NOT displayed on the Listening tab.

## Steps

1. Navigate to Brand > Insights for MTV (verify Data Last Updated present + PT format).
2. Switch to Listening tab.
3. Verify "Data Last Updated" timestamp is NOT shown on the Listening surface.
4. Optionally repeat across 2+ brands to confirm consistency.

## Assertions

| ID | Step | Expected | Actual | Status |
|----|------|----------|--------|--------|
| A1 | 1 | Brand > Insights shows Data Last Updated in `MM-DD-YYYY HH:MM AM/PM PT` format | | |
| A2 | 3 | Listening tab does NOT show "Data Last Updated" element | | |
