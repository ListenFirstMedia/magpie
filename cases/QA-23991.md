# QA-23991 — Reporting > Content Performance Report - Download

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-23991
- **Priority:** Critical
- **Ingested:** 2026-07-22 from Jira (Xray custom fields)

## Preconditions
- User should be logged in as Viacom

## Steps
1. Click Reporting in Top Nav
2. Select 'Content Performance'
3. Click the Competitive set dropdown and Select 'Multiple brands' (if it is not available Create it).
Note: (Add Suits, All NBA, Pretty Little Liars, Michael Kors(Designer), New York Mets and Listening added to 'Multiple Brands' competitive set)
4. Click 'Everything ON' in the data selection
5. Increase Visual Top Posts to 5 and Increase Additional Top Posts to 5
6. Select filter as 'Content Type: Image' from Content and Tag Filters section
7. Click Run Report
8. Click Preview & Share Report button
9. Click Download
10. Open PDF

## Assertions
6. Ensure the available drop down options are: Branded Content, Content Type, Live Stream, Publish Day, Publish Time, Publish Type, Sponsor Name, Tag and Text Search
6. Ensure the filter is selected and Load Filter, Save filter and Clear All options are availabe to filter drop down right side and Load filter is disabled
10. Ensure that each page should display Page N(N - Page count) at the end of the page
10. Ensure the file name should be Primary BrandName - Content Performance(MM DD, YYYY(Start date) - MM DD, YYYY(End Date)).pdf
10. Ensure that the preview mode report page should match with pdf file
10. Ensure in PDF that 'There is no data available. Please select a different brand, brand set, or different range.' message should not be displayed.
