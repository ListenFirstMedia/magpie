## Preconditions
User logged into Dev Radaac (https://radaac.lfmdev.in/).

## Steps
1. In radaac tab, search for report 'Brand Listing'
2. Click "Brand Listing (not full definition)" below Report Name
3. Select Title Category as 'Automotive'
4. Click Submit button

## Assertions
- A1 (3): The Title Category dropdown lists all the active Title Categories
- A2 (4): File name displays as "brands_YYYYMMDD-1032.tsv"
- A3 (4): The following columns are present: brand_id, brand_name, created_at, updated_at, tc_title, tc_display
- A4 (4): The Selected Title Category only (Automotive) displays in the 'tc_display' and 'tc_title' column
