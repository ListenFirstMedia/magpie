# QA-112583 — Reporting > Follower Demographics Vs Threads Audience - Export - Data QA

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-112583
- **Priority:** Blocker
- **Ingested:** 2026-07-13 from Jira (Xray custom fields)

## Preconditions
User should log into Max

## Steps
1. Hover over Reporting in the Top nav and select Follower Demographics in the dropdown
2. Type and Select the Brand "Max"
3. Change the date range to May. 05, 2025
4. Select the Threads channel only
5. Click Run Report
6. Click the Export Button
7. Select CSV
8. Hover over the brand in the top navigation and select Audience
9. Click the Brand dropdown Max.
10. Select 'Max' Brand from the list
11. Change the date range to May. 05, 2025 - May. 05, 2025
12. Select the Threads channel and click Apply
13. Click the Export dropdown in the Followers: Gender Breakdown tile
14. Select CSV from the list

## Assertions
14. Ensure that the exported values from the Followers Demographics report and the Threads Audience Gender Breakdown match.

Note: The audience share value is displayed as a percentage, and the followers demographics report shows it as a float. Convert one format to match both values.
