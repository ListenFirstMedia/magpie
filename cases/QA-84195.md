# QA-84195 — Reporting > Data Studio - Brand > Content -- Data QA - Video Views

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-84195
- **Priority:** Critical
- **Ingested:** 2026-07-13 from Jira (Xray custom fields)

## Preconditions
The user should be logged in as Adam Orfei

## Steps
1. Hover over 'Reporting' in the top nav and select 'Data Studio' in the dropdown
2. Click the Post Level selection and Select 'Aggregate' Interval
3. In the 'Add Brand' textbox, type and choose the brand 'MTV'
4. Click the 'Select Metrics' button and select the following metrics:
   - Facebook Public Views
   - Instagram Public Video Views
   - Twitter Public Views
   - TikTok Video Views
5. Apply filter as 'Content Type: Video'
6. Click the 'Go' button
7. Open a new tab, Click Brand in the top nav, and Select Content
8. Click the Brand drop-down, Type and Select "MTV" brand & Public Perspective
9. Select only the Facebook channel
10. Select only the Instagram channel
11. Select only the Twitter channel
12. Select only the TikTok channel

## Assertions
9. Ensure the following values match between Brand Content and Data Studio for the Facebook channel: Facebook Public Views - Video Views
10. Ensure the following values match between Brand Content and Data Studio for the Instagram channel: Instagram Public Video Views - Video Views
11. Ensure the following values match between Brand Content and Data Studio for the Twitter channel: Twitter Public Views - Video Views
12. Ensure the following values match between Brand Content and Data Studio for the TikTok channel: TikTok Video Views - Video Views
