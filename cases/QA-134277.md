# QA-134277 — Brand > Content - Verify CSV Export respects active Include/Exclude tag filter

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134277
- **Priority:** Critical (P2)
- **Description:** Ensure CSV Export on Brand > Content shows the same posts as the screen, based on selected filters.

## Preconditions
- User logged in as HULU
- 5-6 tagged posts; 2-3 posts with ≥2 tags each

## Steps
1. Brand > Content
2. Select HULU brand
3. Click Filter dropdown → Tag
4. Select Include radio
5. Type any available tag, select it → note as TAG_INC
6. Switch Include to AND
7. Select Exclude radio
8. Type any available different tag, select it → note as TAG_EXC
9. Click Apply Filter
10. Capture POSTCOUNT_A from UI
11. Click Export → CSV
12. Open the downloaded CSV
13. (assertion check)
14. Click Filter Pill to reopen filter
15. Switch Include from AND to OR
16. Click Apply Filter; capture POSTCOUNT_B
17. (capture)
18. Export → CSV
19. (download)
20. Open the downloaded CSV
21. Click Filter Pill to reopen filter
22. Remove existing tags
23. Add a tag that has zero matching posts as Include → note as TAG_NO_RESULTS
24. Click Apply Filter; capture POSTCOUNT_C
25. (capture)
26. Export → CSV
27. (download)
28. Open the downloaded CSV

## Assertions
- A1 (step 9): UI shows posts tagged with TAG_INC, excluding TAG_EXC
- A2 (step 13): Filtered tag only visible in CSV
- A3 (step 16): UI post count updates after switching Include AND → OR
- A4 (step 20): Filtered tag only visible in CSV
- A5 (step 24): UI shows empty state; POSTCOUNT_C = 0
- A6 (step 28): No tag columns in CSV
