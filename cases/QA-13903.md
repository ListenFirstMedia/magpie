# QA-13903 — Embedded Post Tooltip - LinkedIn

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-13903
- **Priority:** Critical (P2)
- **Description:** Ensures embedded versions of Post Table content for LinkedIn tooltip on Brand > Content.

## Preconditions
- User logged in with access to a brand with LinkedIn data (e.g., MTV / Adam Orfei).

## Steps
1. Brand → Content.
2. Type & select brand with LinkedIn (suggest MTV).
3. Select only LinkedIn channel.
4. Choose a recent date range with LinkedIn posts.
5. Select Table view in View mode.
6. Hover over the entry in the Type column for a LinkedIn post (opens embedded post tooltip).

## Assertions
- A1 (6a): Post tooltip displays on hover.
- A2 (6b): Only one tooltip visible at a time.
- A3 (6c): Tooltip closes on X click OR clicking elsewhere.
- A4 (6d): Hovering other Type links doesn't open additional tooltips.
- A5 (6e): Clicking post type opens the correct LinkedIn post in a new tab matching tooltip.
- A6 (6f): Post image (thumbnail) + Post text match the tooltip content.
- A7: No external/non-brand LinkedIn post appears.

## Probes (open bugs)
- APPS-57985 (High, QA Ready) — LinkedIn Posts Thumbnail Issue. Verify whether thumbnails render correctly in the embedded tooltip and on the post card.
