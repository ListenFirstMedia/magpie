# QA-103246 — Brand > Content - Daily Post Analysis Modal - Export - PNG & Google Sheets

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-103246
- **Priority:** Minor (P4)
- **Description:** Verifies PNG + Google Sheets export of the Daily Post Analysis modal on Brand > Content.

## Preconditions
- User logged in with brand having TikTok data (MTV / Amazon Prime Video).

## Steps
1. Brand → Content.
2. Type & select brand (e.g., MTV).
3. Choose date range that includes 2026-05-16 (TikTok endash window) AND at least one different day for control.
4. Click "Daily Analysis" button on a post row.
5. Pick a TikTok post — observe day 2026-05-16 endash behavior.
6. Switch data viz dropdown to Bar.
7. Export → PNG. Verify file in Downloads.
8. Export → Google Sheets. Verify GS opens with same data.
9. Close modal.

## Assertions
- A1: PNG filename pattern `[Brand Name]-Daily Content Analysis-[Graph Type]-YYYY-MM-DD-YYYY-MM-DD.png`.
- A2: ListenFirst logo + brand name in PNG header.
- A3: Date range below the chart.
- A4: PNG matches modal display.
- A5: GS filename `[Brand Name]-[Publish Time]-[Channel]-Daily Content Analysis-...`.
- A6: GS row data matches modal.
- A7 (probe): For 2026-05-16 TikTok day, metric cell shows endash (DATA-12209).
- A8: Close button dismisses modal.

## Probes (open bugs)
- DATA-12209 (Major) — Daily Post Analysis TikTok endash on 2026-05-16.
