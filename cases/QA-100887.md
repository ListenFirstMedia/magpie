## Description
Data Test for brand insights vs TWC comparison

## Preconditions
- User logged in as UCLA

## Steps
1. Click Brand in the top nav and click insights  
2. Click Brand dropdown  
3. Select the brand 'University of California, Los Angeles'  
4. Select "Threads" channel only  
5. Select Date range from Dec, 06, 2024 to Dec, 12, 2024  
6. Note the values of Follower Growth, New Posts, Engagements, Engagement Rate, Views  
7. Click the reporting on the top navigation and select "Time Window Comparison"  
8. Add "University of California, Los Angeles" Brand (Authorized)  
9. Select Absolute Date and Interval as an "Aggregate" and set date to Dec, 06, 2024 to Dec, 12, 2024  
10. Select [ Threads New Followers, Threads Engagements, Threads Posts, Threads Engagement Rate, Threads Views]  
11. Deselect the Show Metrics Graphs Option  
12. Run a Report

## Assertions
12. Ensure the TWC and Brand Insights Values are matching for the selected Metrics
