## Description

This test case ensures on clicking Authorize button, it should open the respective channels "Connect" auth flow, and allow users to multi-select data feeds for 'Threads' channel.

## Preconditions
- Logged in as the test user
- Access to Settings > Data Identities

## Steps
1. Navigate to Settings > Data Identities
2. Verify Instagram Threads row is present in the Data Identities table
3. Click the Authorize button (or check the channel list)
4. Confirm the Connect auth flow is launched for Threads
5. Verify ability to multi-select data feeds for 'Threads'

## Assertions
- Threads data identity is listed
- Authorize CTA opens the Threads/Connect auth flow
- Multi-select of feeds is available
