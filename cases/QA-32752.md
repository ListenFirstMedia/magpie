# QA-32752 — Brand Paid vs TWC > Big Numbers Data QA > Twitter

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-32752
- **Priority:** n/a
- **Ingested:** 2026-10-20 from Jira (Xray custom fields), Test Set QA-26183 "Daily Data Testing -2"

## Description
This Test Case ensures the Big number values between TWC and Brand Paid Tabs

## Preconditions
* User Should LoggedIn Hulu

## Steps
1. Hover Over the Brand from Top Nav and Select Paid  
2. Add Hulu Brand  
3. Enable Twitter Channel Only  
4. Select date range 1/JAN/2025 to 31/JAN/2025  
5. Note the Following Big Number Values [Paid Impressions, Spend, Clicks, Engagements, Retweets]  
6. Hover Over the Reporting from Top Nav and Select Classic Reporting  
7. Select TWC Template  
8. Add Hulu Brand (Authorized)  
9. Select Absolute Dates and Aggregate them as an Interval  
10. In the Data Selection section Select By Channel   
11. Select the Following Twitter metrics [Ad Clicks, Ad Engagements, Ad Impressions, Ad Retweets, Ad Spend]   
12. Deselect "Show Metrics Graphs" option  
13. Click Run Report  
14. Compare the values now

## Assertions
14. Ensure the Paid Page Big Number Values should be matched with the TWC Report values
