## Preconditions
User logged in as Hulu.

## Steps
1. Reporting → Time Window Comparison.
2. Add Hulu, click Authorized toggle.
3. Click By Category.
4. Content → Impressions & Reach → Channel Breakdown.
5. Click By Channel.
6. Instagram → Impressions & Reach → Views, Follower Views, Non-Follower Views, Story Views.
7. Options → Show Metrics.
8. Run Report.
9. Export → CSV.

## Assertions
- A1 (step 2): "Data Last Updated" timestamp visible below Help Centre with format `MM-DD-YYYY | HH:MM AM/PM PT`.
- A2 (step 4): Channel Breakdown shows Instagram Views, IG Follower Views, IG Non-Follower Views, IG Story Views.
- A3 (step 8a): Report loads with data for all 4 metrics.
- A4 (step 8b): Timestamp retains format, not clickable.
- A5 (step 9a): Page data matches CSV data.
- A6 (step 9b): CSV shows metric names + keys when Show Metrics enabled.
- A7 (step 9c): Data Last Updated NOT in CSV export.
