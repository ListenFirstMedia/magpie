## Description
This test case ensures the Same Brand Benchmark - Data QA

## Preconditions
* User logged in as Disney Ad Sales

## Steps
1. Click Brand in nav and click Content  
2. Enter 'Disney Channel' in the brand search input box and select the brand  
3. Select the 'TikTok' Channel only  
4. Change the date range to last 7 days  
5. Click the Benchmark button  
6. Click Set To Current Brand In the Brand field enter  
7. Click Benchmark Period dropdown and Select Rolling 7 Days  
8. Click the Go button

## Assertions
8. Ensure that the values shown in the Aggregate row for Owned Average and Benchmark average are the same or differ by a small percentage for Engagements, Reactions, Comments and Shares  
NOTE: The values for each column being off by 1 or 2 is not an issue.
