- **Priority:** P? (Metric Export)
- **Description (from Jira):** Ensures the Metric Export functionality on the Brand Audience page for the LinkedIn channel.

## Preconditions
- User logged in.
- Brand with LinkedIn audience data (UCLA per QA-92735 bug; switch account if needed).

## Steps
1. Brand → Audience.
2. Select brand with LinkedIn data (UCLA).
3. Filter to LinkedIn channel only.
4. Default Basic view (or whatever view exposes audience tiles).
5. For at least one tile (e.g., Followers: Industry / Job Function / Seniority / Staff Count Range / Followers By Country / Region), open the per-tile Export menu (kebab / Export dropdown) — select `Metrics` / CSV / Google Sheets export option.
6. Capture the saved file (`~/Downloads`). Open + verify column structure and at least one numeric value.
7. Probe APPS-58574 — measure first-row card alignment; report REPRODUCED if first card alone on row 1.

## Assertions
- A1: Brand > Audience LinkedIn page loads (sibling to QA-92735 A1).
- A2: Per-tile Export menu lists Metrics / CSV / GSheets.
- A3: Selecting CSV / Metrics produces a saved file with reasonable filename (`<Brand>-<Page>-<Date>-<Metric>.csv` or similar).
- A4: Saved file content is a real CSV with header row + data row(s).
- A5 (probe): APPS-58574 LinkedIn card misalignment — DOM measurement re-confirms or refutes.
