## Steps
1. Hover over the Brand from Top Nav Select Insights  
2. Add Amazon Prime Video | Gatorade Brand  
3. Select Facebook, Instagram, Twitter, and TikTok Channels  
4. Note the Video Views value on Video Views Tile  
5. Hover over the Reporting from Top Nav Select Classic Reporting  
6. Select TWC Template  
7. Add Amazon Prime Video (Authorized) | Gatorade(Authorized)  
8. Select Absolute Date and Interval as an "Aggregate"  
9. Click By Channel on data Section  
10. Select [ Facebook Page Video Views, Twitter Public Video Views, Instagram Video Views, TikTok Public Video Views.]  
11. Deselect the Show Metrics Graphs Option  
12. Run Report sum all channel's video views value

## Assertions
12. Ensure the brand Insights Cross Channel Video Views Values should be Equal to the Sum of Video Views value of the TWC Report
