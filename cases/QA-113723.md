# QA-113723 — Admin - Brand Set Creation and Settings > Audit screen

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-113723
- **Priority:** Minor
- **Ingested:** 2026-07-13 from Jira (Xray custom fields)

## Preconditions
The user should be logged in as Drylogics
Only execute on Dev
This test case should only be executed on Thursday

## Steps
1. Hover over the key icon on the top right
2. Click on 'Admin'
3. Hover on 'Data' on the top nav and click on 'Brand Sets'
4. Click on the 'New Brand Set' button in the top right corner
5. Enter Name, and Display name
6. Click on 'Title Category' dropdown and select 'Beverages'
7. Click on the 'Create Brand Set' button
8. Sign in to app.lfmdev.in as 'Drylogics'
9. Navigate to Settings > Audit page

## Assertions
7. Ensure the brand is updated
9(a). Ensure the Account column displays as 'Drylogics'
9(b). Ensure the Actor column displays your name
9(c). Ensure the Activity Type column is displayed as 'Brand Set Created'
9(d). Ensure the Description is displayed as 'Brand Set #{brand Set name} was created.'
