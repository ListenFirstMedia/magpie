## Description
* This test case is to ensure Brand Content Post Count Matches With TWC

## Preconditions
* User Should Log in to Viacom

## Steps
NOTE: Select reel filter from the publish type and click exclude and apply the filter (For Facebook Only)

1. Hover over the brand in the top navigation and select Content  
2. Click the Brand dropdown and enter "MTV" Select "MTV" from the list  
3. Select "Facebook" channel only and click apply  
4. Click the filter dropdown and select Content type   
5. Select "Video" from the list and click apply  
6. Note down the post count  
7. Hover over the reporting from the top navigation and click classic reporting  
8. Select "Time Window Comparison" from the sub-menu  
9. Add MTV Brand (Authorized)  
10. Select Absolute Dates and Aggregate them as an Interval  
11. Select the Following metrics [Video Posts, Facebook Video Posts, Twitter Video Posts, Instagram Video Posts, TikTok Video Posts, YouTube Posts]  
12. Deselect "Show Metrics Graphs" option  
13. Click Run Report  
14. Compare the values now  
[Repeat the same steps for Twitter, Instagram, TikTok and Youtube Channels]

## Assertions
14. Ensure the Brand content post count should be matched with the TWC Report values
