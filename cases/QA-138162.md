# QA-138162 — Brand > Content - Verify Select All checkbox functionality in Tag filter

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-138162
- **Priority:** Major
- **Ingested:** 2026-07-13 from Jira (Xray custom fields)

## Preconditions
-User should be logged in As HULU
-Navigate to the post detail view and record at least 3-4 tags associated with the posts. If such posts do not exist, add the required tags and delete them after the test is complete.

## Steps
1. Go to the Brand > Content page
2. Select the HULU brand
3. Open the Filter dropdown and choose the Tag filter
4. Observe whether the "Select All" checkbox is visible without entering any search text
5. Observe the exact placement of "Select All" relative to OR/AND operators and the tag list
6. Observe the default state of "Select All" before selecting any tag
7. Type a search term that matches multiple tags
8. Click "Select All" while search is active
9. Click "Select All" again to deselect while search is still active
10. Clear the search field and observe tag selections
11. Type a search term that matches NO tags
12. While no tags match, click "Select All" and observe what happens
13. Clear search. Click "Select All" to select all tags
14. Manually uncheck one tag after Select All
15. Click "Select All" again after partial selection
16. Click Apply Filter with all tags selected
17. Observe how the selected tags reflect in the Filter section (filter pills)
18. Manually select multiple tags one by one, Apply, and compare the filter pill behavior with Select All
19. Reopen the filter. Switch to Exclude mode and observe "Select All"
20. Switch back to Include mode and observe "Select All"

## Assertions
1. Brand > Content page loads successfully
2. HULU brand is selected and data loads
3. Tag filter dropdown opens showing all available tags
4. "Select All" checkbox is visible even without any search input
5. "Select All" is placed between the OR/AND operators and the tag list, separated by a line break
6. "Select All" is unchecked by default
7. Search results display only matching tags
8. Only the visible/filtered tags are selected, not all tags
9. Only the visible/filtered tags are deselected
10. Previously selected tags from other actions remain intact
11. "Select All" checkbox remains unchecked when no tags match the search
12. Clicking "Select All" when no tags match does nothing — no tags are selected and checkbox remains unchecked
13. All tags are selected
14. "Select All" changes to unchecked state
15. All tags are re-selected, including the previously unchecked one
16. Filter is applied and filter pill shows the selection
17. Tags reflect in the Filter section the same way as selecting multiple tags manually
18. Filter pill behavior is identical whether tags were selected via Select All or manually one by one
19. "Select All" is disabled in Exclude mode
20. "Select All" is available and functional in Include mode
