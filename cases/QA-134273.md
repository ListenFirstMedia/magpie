# QA-134273 — Brand > Content - Verify all four AND/OR operator combinations return correct datasets

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134273
- **Priority:** —
- **Description:** Ensures each combination of Include and Exclude operators (AND+AND, OR+OR, AND+OR, OR+AND) returns the correct and distinct dataset.

## Preconditions
- User logged in as Adam Orfei
- Brand with multiple tags available

## Steps
1. Navigate to Brand > Content
2. Open Filter → Tag
3. Build Include-Or (2 tags), Apply, record Posts count
4. Edit pill to Include-And, Apply, record Posts count
5. Add Exclude-Or (1+ tags), Apply, record Posts count
6. Switch Exclude to And, Apply, record Posts count
7. Combine all 4 variants of Include + Exclude

## Assertions
- A1: Each combo URL `filters` JSON encodes correct `operator` + `not` value
- A2: Posts count differs across 4 combos (distinct datasets)
- A3: Mechanic verified at pill / URL layer
