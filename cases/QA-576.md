# QA-576 — Instagram Lifetime Public Data QA

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-576
- **Priority:** n/a

## Description
This test case ensures that Public Lifetime data in the Instagram post table is displaying correctly

## Preconditions
* User logged in as Netflix Sustainability Team

## Steps
1. Click Brand Sets in the top x nav and Select Content  
2. Click the Brand set drop-down and Type and Select LF // TV // Episodic Plus  
3. Enable only Instagram  
4. Click Add filter and Apply filter as Content Brand :  The Walking Dead  
5. Open a new tab, Click Brand in the top x nav, and Select Content  
6. Click the Brand drop-down and Type and Select The Walking Dead  
7. Select only Instagram  
8. Click Table view in view mode  
9. Click the Engagements column  
10. compare data for the top post in Content Tab to Brand Sets  
11. On the Brand Sets page, select rank by as Comments  
12. in brand content,  Sort Content tab by Comments  
13.  Compare data for the top post in Content Tab to Brand Sets  
14. On the Brand Sets page, select rank by as Reactions  
15. in brand content,  Sort Content tab by Reactions  
16. Compare data for the top post in Content Tab to Brand Sets Reactions.

## Assertions
* Ensure that Content tab Engements matches Content Brand Sets Content Engagements
* Ensure that Content tab Comments matches Content Brand Sets Content Comments
* Ensure that Content Tab Reactions matches Content Brand Sets Content Reactions
