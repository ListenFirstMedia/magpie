## Preconditions
The user should be logged in as Adam Orfei.

## Steps
1. Hover over 'Reporting' in the top nav
2. Click 'Data Studio' in the dropdown
3. Click the Interval dropdown and select 'Days'
4. Click the text box near the "Add a Brand" option.
5. Type and select 'Food Network' and 'Disney Channel' brands
6. Click the Select Metrics button and Select 'Fan Growth Rate' Metric under the Fan Growth Rate Node and select 'Facebook Engagements, Youtube Engagements' under the engagement node
7. Click the Go button
8. Click Export dropdown and Click 'PNG'

## Assertions
- A1 (8): File name is displayed as 'Food Network(Primary Brand Name)-Data-Studio-Graph Title(First metric name)-Line-YYYY-MM-DD-YYYY-MM-DD.png'
- A2 (8): The report matches the PNG export
- A3 (8): LISTENFIRST header with logo displays on the top left corner of the PNG
- A4 (8): Header displays as 'Fan Growth Rate' under the LISTENFIRST header
- A5 (8): Legend: Food Network and Disney Channel are available
- A6 (8): 'Reporting Data Studio with Listenfirst icon' and 'Date Range' displays under the table
- A7 (8): Dates are displayed on the X-axis
- A8 (8): Rate values are displayed on the Y-axis
