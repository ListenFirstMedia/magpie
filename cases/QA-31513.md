## Description
This test case ensures the reels post should have the Impressions data and the Impressions data should be equal to the Plays Value

## Preconditions
* User Should be logged in to Amazon Prime Video

## Steps
1. Hover over the Brand from the Top Nav and Select Content  
2. Add Amazon Prime Video Brand  
3. Select Facebook Channel only and date range as 1/Jan/2025. to 10/Jan/2025  
4. Select the Impressions data set  
5. Apply filter as "Publish Type: Reel"  
6. On the Aggregate table, divide the value of Engagements by Impressions and multiply by 100  
7. Note the aggregate Impressions value  
8. Select Reels Data set  
9. Note the aggregate Plays Value

## Assertions
5. Ensure the Reels post should have Impressions data  
6. Ensure the Calculated value is equal to the Engagement Rate value  
9. Ensure the Impressions value is equal to the Plays value
