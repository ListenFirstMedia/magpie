- **Priority:** n/a
- **Ingested:** 2026-10-20 from Jira (Xray custom fields), Test Set QA-26183 "Daily Data Testing -2"

## Description
This test case ensures the Twitter video views data should be the same for both Public and Authorized data

## Preconditions
- User logged in as Amazon Prime Video

## Steps
1. Hover over the Brand Sets from the top nav and Select Content  
2. Add "Amazon Prime Video-- Episodic Network Roll-Up " Brand Set  
3. Select Video Views(Public Data) on Rank Dropdown  
4. Enable only a Twitter Channel  
5. Note the Video Views value from all posts  
6. Select Video Views(Authorized Data) on Rank Dropdown  
7. Note the post video views value and Compare

## Assertions
7. Ensure the Public and Authorized Video Views data are the same for all posts
