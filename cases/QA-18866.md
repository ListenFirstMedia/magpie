## Preconditions
User logged into Mixpanel Dev:
- https://mixpanel.com/report/1485629/dashboards#
- https://mixpanel.com/project/1485629/view/35285/app/insights#VrFYpPvux7wA

## Steps
1. Reports section → click.
2. Click Insights in the popup.
3. Add → Event in Events & Cohorts.
4. Type and select **Session Start**.
5. Add → Event in Events & Cohorts.
6. Type and select **Session End**.
7. Click **Today** in Time Range.
8. Click "Line" dropdown on right → select **Bar**.
9. Breakdown → Add → **Name**.
10. Breakdown → Add → **Status**.
11. Breakdown → Add → **Email**.
12. Breakdown → Add → **Customer**.
13. Breakdown → Add → **Subscriber Name**.
14. Breakdown → Add → **Business Unit (Client)**.

## Assertions
For each breakdown column, no Undefined / Null / Empty cells should appear:
- **A1 (step 9):** Name column — no Undefined/Null/Empty.
- **A2 (step 10):** Status column — no Undefined/Null/Empty.
- **A3 (step 11):** Email column — no Undefined/Null/Empty.
- **A4 (step 12):** Customer column — no Undefined/Null/Empty.
- **A5 (step 13):** Subscriber Name column — no Undefined/Null/Empty.
- **A6 (step 14):** Business Unit (Client) column — no Undefined/Null/Empty.
