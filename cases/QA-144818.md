## Description
This test case ensures the Last Collection Date is not earlier than the most recent collected post, covering the defect raised in APPS-61562.

## Preconditions
- User logged in as Apple Services  
- Regression coverage for APPS-61562; the original defect reproduced on Dev only

## Steps
1. Click Settings in the top right corner and click Data collection  
2. Search the Apple Music brand name and select it  
3. In the Channel column, select Instagram  
4. Review the 'Data Collection Summary' page and note the Last Collection Date  
5. Navigate to Brand > Content, select Apple Music and the Instagram channel  
6. Note the publish date of the most recent post returned  
7. Repeat steps 2 to 6 on Prod and compare against the Dev result

## Assertions
4. Ensure the Last Collection Date is populated and is not a placeholder or null  
6. Ensure the Last Collection Date is not earlier than the publish date of the most recent post shown on Brand > Content  
6. Ensure the same reconciliation holds on Brand > Insights for the same brand, channel and range  
7. Ensure the behaviour is consistent between Dev and Prod, since the original defect was environment specific
