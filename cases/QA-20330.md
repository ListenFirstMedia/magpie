## Steps
1. Hover over the Brand and Select Content from the Top Nav  
2. Add a Brand and Select a date range as Jan. 01, 2024 - Dec. 31, 2024  
3. Select YouTube Only: Insights   
4. In Each grid post, Add the values of Organic Watch Time (Minutes) and Paid Watch Time (Minutes)  
5. In Each grid post Add the values of Organic Views, Paid Views, and Unclassified views  
6. Select Youtube Only: & Premium Dataset  
7. In Each grid post, Add the values of Organic Premium Views and  Paid Premium Views  
8. In Each grid post, Add the values of Organic Premium Watch Time (Minutes)  + Paid Premium Watch Time (Minutes)

## Assertions
4. Ensure the Sum of the Organic Watch Time (Minutes), and Paid Watch Time (Minutes), value should be equal to Youtube Watch Time (Minutes)  
5. Ensure the Sum of the Organic Views, Paid Views and Unclassified views value should be equal to Video Views Value

7. Ensure the Sum of the Organic Premium Views and Paid Premium Views equal to the Premium Views  
8. Ensure the Sum of the Organic Premium Watch Time (Minutes), and Paid Premium Watch Time (Minutes), the value should be equal to Premium Watch Time (Minutes)

Youtube Watch Time (Minutes) = Organic Watch Time (Minutes) + Paid Watch Time (Minutes),  
Premium Watch Time (Minutes) = Organic Premium Watch Time (Minutes) + Paid Premium Watch Time (Minutes)  
Premium Views = Organic Premium Views + Paid Premium Views  
Video Views = Organic Views + Paid Views + Unclassified views
