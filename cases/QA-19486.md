## Preconditions
User is logged in. Social Recap builder accessible at app-reporting.lfmdev.in/#/social_recap.

## Steps
1. Navigate to Reporting → Social Recap.
2. Add one brand (single-brand variant) — e.g. Hulu — via Add Brand By Name (Rule 1: exact-match from Results).
3. Set a recent date range (default Last 7 Days is fine).
4. Run Report.
5. Once the built report loads, click Export → Preview & Download → PDF.
6. Wait for the PDF to download.
7. Verify the PDF content by rendering to PNG with pdftoppm and reading each page image.
8. Repeat with a multi-brand variant (e.g. Hulu + HBO Max, or another pair).

## Assertions
A1. The PDF downloads to disk with a sensible filename.
A2. The first page contains the report title with brand name(s) + date range.
A3. Each tile/section from the in-app report (Top Performing, Engagement Breakdown, etc.) appears in the PDF.
A4. Multi-brand PDF correctly interleaves or aggregates by brand per template.
A5. Footer/header are rendered without "undefined" or template-leakage strings (LFMP-31798 / BC-4 pattern guard).
A6. APPS-55559 known-quirk: single-channel video views donut may render incorrectly — note but do not fail on it.
