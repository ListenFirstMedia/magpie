## Steps
1. Click Reporting in Top Nav
2. Select 'Time Window Comparison'
3. Add brand as MTV
4. Select Absolute Date Range and Select Weeks Interval.
5. Change date range to Apr 09, 2025 - Apr 15, 2025
6. Click By Channel and Select ' ALL On' for Facebook.
7. Select Interleave Graphs & Tables
8. Select Run Report
9. Click Preview & Share Report button
10. Click Download
11. Open PDF
12. Click the close button on the Preview page
13. Click Change settings, and click the Competitive Set dropdown
14. Type and select 'ATV Competitive Set'
15. Click Run Report
16. Click Preview and Share Report and select download
