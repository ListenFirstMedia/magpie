## Preconditions
-Use all the Accounts to login for each day of testing
-Select relevant brands mapped to their respective accounts
-For each day, test all related channels Facebook, Instagram, Twitter, Threads, TikTok, Wiki, Pinterest, YouTube, LinkedIn for the selected Brand and Account

## Steps
1. Click Settings in the top right corner and click Data collection
2. Search Brand name and select it .
3. In Channel Column ,Select Channel
4. In the Pages section, Click on Brand Name
5. Review the 'Data Collection Summary' Page

## Assertions
3. Ensure selected channel filter is applied and only data feeds for that channel are displayed
4. Ensure 'Data Collection Summary' page opens
5a. Ensure if 'Status' column displays 'Collecting' it should display with green check icon
5b. Ensure 'Last Collection Date' column displays the current date or the day before if Status is 'Collecting'
5c. Ensure if Status is 'Collecting', data is visible on the Brand Content page matching the Native source with the latest collection date
5d. Ensure if 'Status' column displays 'Not Collecting' it should display with red exclamation icon
5e. Ensure if 'Status' column displays 'To Do' it should display with blue plus icon
