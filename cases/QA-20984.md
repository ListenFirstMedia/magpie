## Description
This test case ensure Data QA - TikTok

## Preconditions
* User logged in as Amazon Prime Video

## Steps
1. Hover over Brand in Xnav and select Paid in the dropdown  
2. Click the Brand dropdown and Type  Amazon Prime Video  
3. Select  Amazon Prime Video Brand from the list , Select Date range from Feb 01, 2025, to Mar 31, 2025  
4. Select 'TikTok' channel only and click Apply button  
5. Click Table View and Scroll to the bottom of the post table  
6. Hover over big numbers  
7. Click the View data set drop-down and select Video Play  
8.  Hover over 100% Completed Views big number  
9. Click table data set drop-down and select Reach  
10. Hover over Reach big number  
11. Hover over Paid Impressions Bignumber

## Assertions
6. Ensure post table header, total posts displaying in the post table, and Active Ads match  
6. Ensure that the following big numbers and aggregate row in the post table match based on the View Data Set and Big Number pairing: Spend, Clicks  
8. Ensure that the following big number and aggregate row in the post table match based on the View Data Set and Big Number pairing Video Play: 100% Completed Views  
10. Ensure that the following big number and aggregate row in the post table match based on the View Data Set and Big Number pairing Reach: Paid Reach  
11. Ensure that the following big number and aggregate row in the post table match based on the View Data Set and Big Number pairing Reach: Paid Impressions
