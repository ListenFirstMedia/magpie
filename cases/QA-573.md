# QA-573 — YouTube Lifetime Public Data QA

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-573
- **Priority:** n/a

## Description
This test case ensures that Public Lifetime data in the YouTube post table is displaying correctly

## Preconditions
* User logged in as Viacom

## Steps
1. On the Start screen, select Brand Sets - Content  
2. Select 'LF // TV // Episodic' brand set and Click the Search button  
3. Select Table view in view mode  
4. Click Filter dropdown and select Content Brand: The Daily Show  
5. Click Youtube channel only in channel toggle  
6. Right Click and open Brand - Content in another tab  
7. Enter 'The Daily Show' in the brand search input box and select the brand  
8. Click 'YouTube' channel only in channel toggle  
9. Select Table view in view mode  
10. Click Rank by Comments in Brand Sets content page  
11. Click 'YouTube' channel only in channel toggle  
12. Click Sort by Comments in Brand content page  
13. Compare the comments in brand content and Brand Sets page  
14. Click Rank by Reactions in Brand Sets content page  
15. Click 'YouTube' channel only in channel toggle  
16. Click Sort by Reactions in Brand content page  
17. Compare the Reactions in brand content and Brand Sets page  
18. Click Rank by Video Views in Brand Sets content page  
19. Click 'YouTube' channel only in channel toggle views  
20. Click on Video Views header in brand content page  
21. Compare the Video views in brand content and Brand Sets page

## Assertions
13. Ensure the Comments value should be matched  
17. Ensure the Reactions value should be matched  
21. Ensure the video views value should be matched
