# QA-110083 — Settings > Audit – Brand Set Created - Audit Actions Functionality

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-110083
- **Priority:** standard
- **Description:** Verifies the creation of a new Brand Set is properly tracked in the Audit tab.

## Preconditions
- User logged in.
- Account has Brand Sets feature available.

## Steps
1. Settings → Audit.
2. Note current audit row count / latest row.
3. Open another tab → Brand Sets → Create New Brand Set (provide name + select brands) — MUTATING.
4. Save the new brand set.
5. Return to Settings → Audit; refresh.
6. Verify new audit row appears with Activity Type indicating Brand Set creation.
7. Verify Description column references the newly-created brand-set name.
8. Cleanup — delete the test brand set.

## Assertions
- A1: A new Audit row exists post brand-set creation.
- A2: Activity Type column contains 'Brand Set Created' (or equivalent).
- A3: Description column contains the new brand-set name and actor.
- A4: Date column matches creation timestamp.
- A5: Actor column populated with current user's name.
- A6: After cleanup, a corresponding "Brand Set Deleted" Audit row exists.

## Notes
