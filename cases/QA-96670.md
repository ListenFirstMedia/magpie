## Preconditions
Logged in as Max.

## Steps
1. Brand → Insights.
2. Brand = Max.
3. Channels selector → Threads only, Apply.
4. Hover bar chart below New Posts big number.
5. Hover area chart in Views tile.
6. Click Graph Type dropdown in New Posts tile.
7. Select Pie, hover pie chart.

## Assertions
- A1 (3): Graph type dropdown + Export + Save to Dashboard appear for all big numbers.
- A2 (4a): Bar-chart hover tooltip: `Mon. DD, YYYY` / `icon channel name: value`.
- A3 (4b): Bar color matches legend color.
- A4 (5): Area-chart tooltip: `MMM.DD,YYYY : Value` / `icon channel name: value`.
- A5 (7): Pie tooltip: `Channel icon Threads: value`.
