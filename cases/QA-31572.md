# QA-31572 — Brand Insight vs Classic Reports > Data Test >   Impressions

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-31572
- **Priority:** n/a
- **Ingested:** 2026-10-20 from Jira (Xray custom fields), Test Set QA-21686 "Daily Data Testing -3"

## Description
This Test case ensures that the BPC data matches Classic Reporting BPC data.

## Preconditions
* User should be logged in to Amazon Prime Video

## Steps
1.  Hover over the Brand from Top Nav and select Insights  
2. Enable [Facebook, Twitter, Instagram] channels Only  
3. Note the Impression's big number value  
4. Hover over the Reporting from Top Nav and Select Classic Reporting  
5. Select the TWC template  
6. Add Amazon Prime Video Brand (Authorized)  
7. Select Absolute Dates and Aggregate Interval in the Select a Date Range section  
8. Select By Channel  
9. Select [Facebook Page Impressions, Twitter Organic Post Impressions, Instagram Post Impressions]  
10. Run Report

## Assertions
10. Ensure the Sum of selected report value matches with the brand insights impressions data
