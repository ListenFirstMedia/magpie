# QA-92841 — Reporting > Data Studio - Save Breakdown Table to Dashboard - PNG & Google Sheets Exports

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-92841
- **Priority:** Minor (P4)
- **Description:** Verifies saved dashboard tile behavior with breakdowns added on the Data Studio source. Validates PNG + Google Sheets exports from the saved-dashboard surface.

## Preconditions
- User logged in (Adam Orfei works).
- A Data Studio Brand Insights / Brand Content report run with a Breakdown (e.g., Channel) applied.

## Steps
1. Navigate to Reporting → Data Studio.
2. Build a report (Brand Insights → 1+ brand, 1+ metric, choose a Breakdown such as Channel).
3. Click "Run".
4. Confirm data-fetching popup appears while loading.
5. After data loads, click "Save to Dashboard" → choose existing dashboard → Save.
6. Navigate to the dashboard.
7. On the saved breakdown table tile, click Export → PNG. Inspect the saved file in Downloads.
8. Click Export → Google Sheets. Confirm the GS file opens.
9. Verify the PNG and Google Sheets match the on-screen breakdown table.

## Assertions
- A1: Data fetching popup is visible during Run on the Data Studio page (probe LFMP-31814).
- A2: Tile saves to dashboard with the breakdown applied.
- A3: PNG filename pattern present, image renders the breakdown table.
- A4: Google Sheets export contains the same rows / breakdown as on-screen.
- A5: Authorized Video Views column consistent (lock vs endash) — probe LFMP-31936.

## Probes (open bugs)
- LFMP-31814 (Major) — DS Data fetching pop-up not displayed.
- LFMP-31936 (Minor) — Authorized Video Views inconsistency (lock vs endash).
