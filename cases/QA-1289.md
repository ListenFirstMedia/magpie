## Description
This test case verifies Facebook Content tag filter functionality, including Select All checkbox behavior.

## Preconditions
User logged in as Adam Orfei. FB-eligible brand with existing tags.

## Steps
1. Brand → Content, Facebook channel only.
2. Open Filter dropdown → Tag section.
3. Observe Select All checkbox default state.
4. Click Select All, observe all tags selected.
5. Deselect, observe individual tag selection still works.
6. Apply Filter.

## Assertions
- A1: Tag filter section renders with Select All checkbox.
- A2: Select All checkbox toggles all tag checkboxes.
- A3: Individual tag selection works independent of Select All.
- A4: Apply Filter narrows post list to tagged posts.
