## Preconditions

## Steps
1. Reporting → Data Studio.
2. Click Add a Brand textbox.
3. Type and select Michael Kors and MTV. (MTV will be added Public.)
4. Add MTV again, toggle Authorized.
5. Select Metrics → Facebook Engagements + Twitter Engagements under Engagements.
6. Click Go.

## Assertions
- A1 (4): Allows adding a brand with different perspectives (Public + Authorized).
- A2 (6a): Data displays for selected brands.
- A3 (6b): MTV appears with both Public and Authorized in legend (`MTV P` and `MTV`).
