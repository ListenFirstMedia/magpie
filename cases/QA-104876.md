## Description

This test case ensures the Delete Functionality of the Custom Data Set listing table in the Settings Custom Data Set tab.

## Preconditions
- Logged in as the test user
- A test Custom Data Set exists (or can be created/cleanup)

## Steps
1. Navigate to Settings > Custom Data Sets
2. Identify a target Custom Data Set row
3. Open the Actions ellipsis menu
4. Click Delete
5. Confirm in the modal
6. Verify the row is removed from the listing
7. Verify on refresh the deletion persists

## Assertions
- Delete confirmation modal appears with proper messaging
- After confirm, row is removed from table
- Refresh-persistent
