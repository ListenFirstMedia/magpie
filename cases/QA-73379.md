## Description
This test case includes the current data set exported behavior.

## Preconditions

## Steps
1. Click Brand in the top nav and click Content.
2. Enter and Select the brand 'MTV'.
3. Click the Data Set drop-down and select Public data set.
4. Enable only Facebook Channel.
5. Click the Export button and select Current Data Set in CSV.

## Assertions
