# QA-116173 — Sentiment Export Email, Notification & Auto Download

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-116173
- **Priority:** Minor
- **Description:** Ensures the Sentiment Export's Email, bell icon & Auto Download functionality.

## Preconditions
- User should be logged in as Amazon Prime Video.

## Steps
1. Hover the Brand top nav and select content
2. Click Brand search drop down and type 'Amazon Prime Video'
3. Select the 'Amazon Prime Video' brand
4. Click the Sentiment button
5. Click on the Sentiment Export button.
6. In Sentiment Export Pop Up Click on OK

## Assertions
- A1 (step 6): Ensure a notification appears with a bell icon and includes a message containing the download file link 'Download file'
- A2 (step 6): Ensure the CSV file is automatically downloaded.
- A3 (step 6): Ensure the Same Notification Received on email and clicking the attachment successfully downloads the file.
