# QA-134276 — Brand > Content - Verify Exclude-only filter returns correct results for OR and AND operators

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134276
- **Priority:** —
- **Description:** Ensures OR removes posts matching any excluded tag and AND removes only posts matching all excluded tags. Red pills shown for Exclude tags.

## Preconditions
- User logged in as Adam Orfei
- Brand with at least 2 tags shared across some posts (MTV)

## Steps
1. Navigate to Brand > Content (MTV, IG)
2. Open Filter → Tag — switch radio to Exclude
3. Add 2+ Exclude tags
4. Apply with OR — record Posts(N) for OR
5. Re-open pill → switch to AND → Apply — record Posts(N) for AND
6. Verify pill colors red
7. Verify URL `filters` JSON encodes `operator:or` / `operator:and` with `not:true`

## Assertions
- A1: OR Exclude count ≤ AND Exclude count (OR removes more — i.e., AND result ≥ OR result)
- A2: AND requires explicit click; not selected by default after enablement
- A3: Pill chips are red
- A4: URL `filters` JSON encodes `operator` correctly and `not:true`
- A5: Posts table updates after each Apply
