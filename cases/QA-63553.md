## Steps
1. Settings → Tags.
2. Click Filter dropdown → select Tag.
3. Hover long tag name with ellipses (in dropdown).
4. (Likely step duplicated in case wording.)
5. Type and select `nba`.
6. Apply Filter.
7. Click NBA tag in tag column.
8. Hover post Text.
9. Hover Tags in Tag Name column.
10. Scroll bottom.
11. Click a Brand name.

## Assertions
- A1 (step 6): Selected tag data displays.
- A2 (step 8): Tooltip shows full post text.
- A3 (step 9): Tooltip shows tag names.
- A4 (step 10): 200 more posts load.
- A5 (step 11a): Navigates to Brand Content Page.
- A6 (step 11b): Only selected brand in brand dropdown.
