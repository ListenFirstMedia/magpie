## Description
TSV exports of a TWC report built with Relative Dates display the correct absolute dates.

## Preconditions
User logged in as Adam Orfei (account_id=54). MTV / Hulu / Disney Channel available as standard test brands.

## Steps
1. Reporting → Time Window Comparison.
2. Select **Relative Dates**.
3. Add 1+ brand(s) (e.g. Hulu).
4. Add 1+ data point(s) (e.g. Facebook New Fans).
5. Run Report.
6. Export → TSV.
7. (Compare) Export → CSV.
8. (Compare) Export → XLS.
9. (Compare) Export → Google Sheets.

## Assertions
- A1 (step 5): Report renders Relative Dates with concrete absolute date X-axis labels.
- A2 (step 6): TSV file downloads with `.tsv` extension and tab-separated payload.
- A3 (step 6): TSV header rows contain Brand + Metric labels matching the report.
- A4 (step 6): TSV date column contains the absolute dates derived from the relative range (no `Last 7 Days` placeholder).
- A5 (step 6): TSV numeric cells match the rendered TWC tile values (rate metrics as float).
- A6 (step 6): En-dash (`–`) absent in TSV cells.
- A7 (steps 7–9): CSV / XLS / Google Sheets payloads numerically match TSV.
