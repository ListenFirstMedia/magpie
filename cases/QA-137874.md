## Preconditions
- Use all the Accounts to login for each day of testing
- Select relevant brands mapped to their respective accounts (HBO Max, UCLA, Apple Services, Spotify → HBO Max, University of California Los Angeles, Apple Music, Spotify News)
- For each day, test channels: Facebook, Instagram, Twitter, Threads, TikTok, Wiki, Pinterest, YouTube, LinkedIn

## Steps
1. Settings → Data Collection
2. Search Brand name and select it
3. In Channel column, select Channel
4. In Pages section, click Brand Name
5. Review Data Collection Summary page

## Assertions
- 3: Selected channel filter is applied; only feeds for that channel are displayed
- 4: Data Collection Summary page opens
- 5a: If Status = Collecting → green check icon
- 5b: Last Collection Date = current date or day before when Collecting
- 5c: If Collecting → data visible on Brand Content page matching Native source with latest collection date
- 5d: If Not Collecting → red exclamation icon
- 5e: If To Do → blue plus icon
