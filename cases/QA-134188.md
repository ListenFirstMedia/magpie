- **Priority:** Blocker (P1)
- **Description:** Verify Brand > Insights tiles render correctly with Monthly interval + Last 3 Months range and exports (CSV/GS) contain accurate data.

## Preconditions
- User logged in as Adam Orfei

## Steps
1. Navigate to Brand > Insights
2. Click Date Range selector
3. Set Interval = Monthly
4. Auto date mode
5. Last 3 Months
6. Observe tiles: Follower Growth, Fan Growth Rate, New Posts, Engagements, Content Engagement Rate, Impressions, Video Views, Brand Reputation Index
7. Verify graph axes + monthly labels
8. Click Export under Follower Growth
9. Select CSV
10. Open exported CSV
11. Compare chart data with CSV
12. Click Export under Follower Growth
13. Select Google Sheets

## Assertions
- A1 (6a): All tiles display successfully
- A2 (6b): No blank state, broken graph, or error
- A3 (7a): X-axis shows selected months (e.g., Jan 2026, Feb 2026, Mar 2026)
- A4 (7b): Y-axis shows numeric values for all tiles except Fan Growth Rate
- A5 (9a): Export → CSV downloads successfully
- A6 (9b): No error during export
- A7 (10a): Filename format `BrandName-Insights-Follower Growth-YYYY-MM-DD-YYYY-MM-DD.csv`
- A8 (10b): Columns Start Date, End Date, Brand Name, Channel, Follower Growth
- A9 (10c): CSV has monthly records for selected range
- A10 (10d): Each row = correct monthly date range
- A11 (11a): CSV data matches page data
- A12 (11b): CSV does NOT contain data outside selected Last 3 Months
- A13 (11c): No duplicates or missing monthly records
- A14 (13): CSV data matches GS data
