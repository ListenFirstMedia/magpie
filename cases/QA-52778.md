## Preconditions
User logged into Dev Radaac (https://radaac.lfmdev.in/).

## Steps
1. In Radaac tab, search and select 'Brand Definitions (Fetch)'
2. Add the value "236" in "Brand IDs (CSV)"
3. Check the 'Include URL Managers' checkbox
4. Click the Submit button
5. Open the Downloaded CSV file and save the file
6. Click Radaac Home button on the top left hand side
7. In Radaac tab, search and select 'Brand Definitions (Patch)'
8. Click the "Choose file" button and upload the saved CSV file
9. Check the 'Include URL Managers' checkbox
10. Click the Submit button
11. Open the downloaded CSV file
12. Click Radaac Home button on the top left hand side
13. In Radaac tab, search and select 'Brand Definitions (Apply)'
14. Click the Choose file button and upload the Downloaded CSV file (Patch report)
15. Check the 'Include URL Managers' checkbox
16. Click the Submit button
17. Open the downloaded CSV file
