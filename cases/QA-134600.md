# QA-134600 — BrandSet > Ranking > Public Video View & Average Public Video View Export Functionality

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134600
- **Priority:** Major
- **Ingested:** 2026-07-13 from Jira (Xray custom fields)

## Preconditions
User should be logged in as Viacom.

## Steps
1. Hover over the Brand Sets dropdown in the top navigation and click Rankings.
2. Select 'LF // TV // Episodic' Brand Set.
3. Click on the 'Rank' dropdown.
4. Select 'Public Video Views' from the rank dropdown.
5. Select 'Instagram' channel only.
6. Click Export Dropdown & Select CSV.
7. Validate the first two rows of the file for correct metadata (date range and metric).
8. Select 'Average Public Video Views' from the rank dropdown.
9. Click Export Dropdown & Select CSV.
10. Validate the first two rows of the file for correct metadata (date range and metric).

## Assertions
6(a). Ensure the file is downloaded with the file name 'BrandSet_Public Video View (Start Date MM.DD.YYYY) - (End Date MM.DD.YYYY)' (Ex. LF_TV_Episodic_Public Video Views (04.08.2026-04.14.2026)).
6(b). Ensure Overall Rank, Filter Rank, Brand, Type, Company, Public Video Views, Instagram Public Video View, Public Video Views - Movement, Instagram Public Video Views - Movement, Instagram Public Video Views - Share columns should be present in the file.
6(c). Ensure file data must match with UI value with correct order.
7. Verify that Row 1 displays the correct date range and matches the UI selected date range (e.g., From: Apr 8, 2026 | To: Apr 14, 2026 | Compare From: Apr 1, 2026 | Compare To: Apr 7, 2026) & Row 2 displays "Metric: Public Video Views".
9(a). Ensure the file is downloaded with the file name 'BrandSet_Average Public Video View (Start Date MM.DD.YYYY) - (End Date MM.DD.YYYY)' (Ex. LF_TV_Episodic_Average Public Video Views (04.08.2026-04.14.2026)).
9(b). Ensure Overall Rank, Filter Rank, Brand, Type, Company, Average Public Video Views, Instagram Average Public Video View, Average Public Video Views - Movement, Instagram Average Public Video Views - Movement, Instagram Average Public Video Views - Share columns should be present in the file.
9(c). Ensure file data must match with UI value with correct order.
10(a). Verify that Row 1 displays the correct date range and matches the UI selected date range (e.g., From: Apr 8, 2026 | To: Apr 14, 2026 | Compare From: Apr 1, 2026 | Compare To: Apr 7, 2026).
10(b). Ensure Row 2 in the file displays "Metric: Average Public Video Views".

## Notes
Per Jira comment thread: the two rank metrics (Public Video Views / Average Public Video Views) are mutually exclusive via the single-select Rank dropdown, so both cannot be validated in a single export — two separate export flows (steps 5-7 and 8-10) is the accepted approach. Also called out as accepted product behavior: a metric with no data/lock icon still appears in the CSV. A negative assertion was requested but not yet reflected in the ticket's formal Assertions field: the CSV under Public Data perspective should NOT contain authorized-only metric columns (e.g., "Page Video Views", "Impressions").
