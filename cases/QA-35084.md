## Description
This test case ensures the Facebook reels data set all views.

## Preconditions
User logged in as Viacom.

## Steps
1. Click Brand in Top nav and Click the Content tab.
2. Enter and Select 'MTV' in brand dropdown.
3. Click Data Set drop-down and select Reels Data Set.
4. Enable the Facebook Channel Only.
5. Click Detail view.
6. Click Table View.

## Assertions
- A1 (step 4): Ensure the default sort is "Engagements" in the dropdown.
- A2 (step 5): Ensure the same metrics are updated in the Detail view.
- A3 (step 5): Ensure the Aggregate table displays the following metrics: "Engagements" and "Follows".
- A4 (step 6): Ensure the following columns are present in the table view: Rank, Date, Channel, Brand, Type, Live, Publish Type, Paid, Sponsor, Collaborated, Text, Engagements, Plays, Follows, Actions.

## Cleanup
None — read-only verification, no mutation.
