# QA-113722 — Admin - User Creation and Settings > Audit screen

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-113722
- **Priority:** Minor
- **Description:** Ensure that the User created in the Admin page is reflected on the Settings > Audit page.

## Preconditions
- User logged in as Drylogics.
- Only execute on Dev.
- Only execute on Thursday.

## Steps
1. Hover over the key icon on the top right.
2. Click on 'Admin'.
3. Hover on 'Accounts' on the top nav and click on 'Users'.
4. Click on the 'New User' button in the top right corner.
5. Enter first name, last name, and Email ID.
6. Click on 'Primary Account' dropdown and select 'Drylogics'.
7. Click on the 'Create User' button.
8. Log in to app.lfmdev.in as 'Drylogics'.
9. Navigate to Settings > Audit page.

## Assertions
- A7 (step 7): Brand/user is updated/created.
- A9a (step 9): Account column displays 'Drylogics' (primary account associated with new user).
- A9b (step 9): Actor column displays your name.
- A9c (step 9): Activity Type column displays 'User Created'.
- A9d (step 9): Description displays 'User #{user name} was created.'

## Notes
- MUTATING — creates a new user; deactivate/clean up after.
- Don't enter a real password; use placeholder; if real sign-in required → PARTIAL.
