# QA-134271 — Brand Navigation — Data Last Updated: Timestamp

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134271
- **Priority:** —
- **Description:** Validates the formatting and accuracy of the ETL Data Refresh Timestamp remains consistent and persistent across navigation between different Brand tabs.

## Preconditions
- User logged in as Adam Orfei

## Steps
1. Navigate to Home and read `Data Last Updated (PT): …` header
2. Navigate to Brand > Insights — verify same timestamp
3. Repeat for Brand > Audience / Content / Channels / Stories / Optimization
4. Refresh (F5) any Brand page — verify timestamp persists
5. Switch to a different brand — verify timestamp persists

## Assertions
- A1-A7: Timestamp consistent across all Brand sub-tabs
- A8: Persists across brand switch (account-wide signal)
- A9: Persists after F5 refresh
- A10: Format conforms to `MM-DD-YYYY HH:MM AM/PM PT` after `(PT):`
