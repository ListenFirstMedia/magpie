## Objective

Verify that on the Brand > Optimization page (`#explore/brand/optimization`), users can simultaneously Include and Exclude tags in the same filter set, mirroring the layered tag filtering feature on Brand > Content.

## Steps

1. Navigate to Brand > Optimization with MTV selected and a representative date range.
2. Open the Filter dropdown and select Tag sub-filter.
3. Verify the Tag popup default = Include + Or/And operator + checkbox list.
4. Add an Include tag with Or operator.
5. Switch to Exclude — confirm Include-selected tags greyed.
6. Add a different Exclude tag.
7. Apply Filter; capture the URL `filters` JSON encoding.
8. Verify the page contents (charts/tables) update with layered filter.
9. Test Or vs And on Include.
10. Clear All filters.
