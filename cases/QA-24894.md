## Steps
1. Hover over the Reporting   
2. Select Social Recap Template  
3. Add the Sephora | Ralph Lauren brand on the brand selection and select Authorized perspective  
4. Select all the channel's data in the data selection  
5. Run the report  
In the "Social Activity - Date - Date" Section  
6. Add the values of Facebook Impressions, Twitter Impressions, Instagram Impressions, Youtube Impressions,Tik tok Paid Impressions, LinkedIn Impressions in the table  
7. Inspect the Impressions Big number value in the Donut chart and note down the data-tooltip value  
8. Add the values of Facebook Video Views( Organic + Paid ), Instagram Video Views, Twitter Video Views, Youtube Video Views, TikTok Video Views, LinkedIn Video views [ Note: Not include Tiktok Paid Video views ]  
9. Inspect the Video Views Big number value in the Donut chart and note down the data-tooltip value  
10. Add the values of Facebook Engagements, Instagram Engagements, Twitter Engagements, Youtube Engagements, TikTok Engagements, LinkedIn Engagements  
11. Inspect the Engagements Big number value in the Donut chart and note down the data-tooltip value  
12. Add the values of Facebook New Followers, Instagram New Followers, Twitter New Followers, Youtube New Followers, LinkedIn New Followers, and TikTok New Followers [ Note: Dont add -ve followers count ]  
13. Inspect the  New Followers Big number value in the Donut chart and note down the data-tooltip value

## Assertions
7. Ensure the Added Impressions value from the table should be equal to the total sum value of impressions displayed in the data-tooltip  
9.Ensure the Added video views value from the table should be equal to the total sum value of video views  displayed in the data-tooltip  
11. Ensure the Added Engagements value should be equal to the total value of Engagements displayed in the data-tooltip  
13. Ensure the Added  New Followers value should be equal to the total value of New Followers which is displayed in the data-tooltip
