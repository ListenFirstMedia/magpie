# QA-130076 — Settings > Notifications - Improve Lost Authorization Messaging

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-130076
- **Priority:** Major (P3)
- **Description:** Verify lost authorization notifications clearly identify the affected feed and brand, and follow consistent message format with troubleshooting guidance.

## Preconditions
- User logged in as Viacom
- Note 1: For first-time setup, navigate to Notification > Subscription section and enable the Data Collection toggle (one-time configuration)
- Note 2: This Test case cannot be executed on Stage

## Steps
1. Click Settings in top navigation, select Notifications from dropdown
2. Review lost authorization notification message displayed

## Assertions (step 2)
- A1: Notification message clearly displays the affected feed name
- A2: Notification message clearly displays the associated brand name
- A3: Notification shows status "NOT COLLECTING"
- A4: Notification message follows standard format: "We lost data collection on the '<feed>' feed for the '<brand>' brand. Please click to troubleshoot"
