## Preconditions
User logged in as Viacom.

## Steps (Run 1)
1. Click Reporting in Top Nav.
2. Select Time Window Comparison.
3. Click 'Add Brand By Name' field → type & select MTV.
4. Select date range = last 7 days.
5. Under Select Channel Data → click (All On) for Facebook.
6. Under Options select:
   - Graph Options → Show Metrics Graphs
   - Table Options → Show Metrics Tables, Set Brands as Rows, Show Change, Show Share
7. Click Run Report.
8. Click Preview & Share Report.
9. Review print preview.

## Steps (Run 2)
10. Click Change Settings → select 'All NBA' brand.
11. Under Select Channel Data → click (All On) for Facebook AND Twitter.
12. Under Options → General → check: Interleave Graphs & Tables, Show Cohort Average, Cohort Average Label = "Cohort Average", Highlight Leader, Show Source Links, Show Insights Editor.
13. Click Run Report.
14. Click Preview & Share Report.

## Assertions
- A1 (9a): All sections + format match report output.
- A2 (9b): No empty pages.
- A3 (9c): No broken images or links.
- A4 (14a): All sections + format match.
- A5 (14b): No empty pages.
- A6 (14c): No broken images or links.
