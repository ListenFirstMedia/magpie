## Description
Data Test for Threads Impressions Data Set

## Preconditions
* User logged in as HBO Max

## Steps
1. Click Brand in the top nav and click Content  
2. Click Brand dropdown  
3. Select the brand 'Max' and Select Date range 1/Jan/2026 to 15/Jan/2026  
4. Click the data set dropdown and Select the Impression dataset  
5. Select "Threads" channel only  
6. In Each grid post Add the values of Organic Impressions, Paid Impressions  
7. In Each grid, post Add the values of Organic Reach, Promoted Reach  
8. Note the values of Engagements and Impressions

## Assertions
6. Ensure the Sum of the Organic Impressions, Paid Impressions value should be equal to the Impressions Value  
7. Ensure the Sum of the Organic Reach, Paid Reach value should be equal to Reach Value  
8. Ensure the division of Engagements and Impressions is equal to the Engagement Rate  
8. Ensure Engaged User Rate displays endash for it

Organic Reach + Promoted Reach = Reach  
Organic Impressions + Paid Impressions = Impressions  
Engagements / Impressions = Engagement Rate
