# QA-32526 — Brand Content Vs Brand Sets Content - Video Views - Private Data QA - Lifetime Mode

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-32526
- **Priority:** n/a
- **Ingested:** 2026-10-20 from Jira (Xray custom fields), Test Set QA-26183 "Daily Data Testing -2"

## Description
This test case ensures that private video views data in Brand Sets content  should match with the video views  data in the brand content post table

## Preconditions
User logged in as Disney Ad sales

## Steps
1. Click Brand Sets in the top nav and Select Content  
2. Click the Brand set drop-down and Type and Select LF // TV // Episodic  
3. Click Rank By Dropdown and Select 'Video Views' under Authorized Data  
4. Enable only Facebook Channel  and select Lifetime Mode  
5. Click Add filter and Apply filter as Content Brand: Disney Channel, Content Type: Video  
6. Click Table view in view mode & select Filtered Rank mode  
7. Open a new tab, Navigate to Brand > Content   
8. Select Brand as Disney Channel & Perspective as Extended  
9.  Select Video Views in the dataset   
10.  select only Facebook Channel and select Lifetime Mode  
11.  Click Table view in view mode  
12. Click the filter dropdown and select publish type and select "Reel", Click "Exclude" filter and click apply (For Facebook Only)  
13. Click the sort icon in the Video Views column  
14. Compare Video Views data for the all post in Content Tab to the Competitive tab  
15. Repeat the same steps to match Video Views data in all other channels [ Twitter, Instagram, Tiktok, YouTube ]

## Assertions
* Ensure that the Content tab Video Views match the Brand Sets Content Video Views (Private Data)
