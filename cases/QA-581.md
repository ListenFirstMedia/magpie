## Preconditions
User logged in as Hulu. User has dev open in 1 browser and stage open in another. (Note: magpie runs against dev only — stage parity is deferred per QA-569 pattern.)

## Steps
1. Click Brand top nav, select Content on stage and dev
2. Click Brand search drop down — type and select Hulu on dev and stage
3. Select 'Twitter' channel on dev and stage
4. Click Content on stage
5. Click Content on dev
6. Change the end date back by 2 days both dev and stage
7. Click on calendar — Select mode as 'In Window' both dev and stage
8. Click view data set drop down and select Impressions
9. On Stage click Impressions
10. Compare impressions data
11. On content, click video view data set
12. On Content, click video view data set
13. Compare video view data

## Assertions
10. Ensure the data for posts in the dev date range match the data on stage for those posts (you will see more posts in stage because of the day ahead)
13. Ensure the number of posts for each view matches
