## Steps

2. Add 'HBO Max' | Hulu Brand and Select Public Data View  
3. Select Facebook, Twitter, Instagram and TikTok Channels  
4. Note the Response Rate value on Response Rate Tile  
5. Hover over the Reporting from Top Nav Select Classic Reporting  
6. Select TWC Template  
7. Add 'HBO Max' | Hulu Brand (Public Data)  
8. Select Absolute Date and Interval as an "Aggregate"  
9. Click By Channel on data Section  
10. Select "Response Rate" User the Cross Channel  
11. Deselect the Show Metrics Graphs Option  
12. Run a Report and Note the Value Of Response Rate Value
