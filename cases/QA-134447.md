## Objective

Verify Brand > Paid supports simultaneous Include + Exclude tag filtering with OR/AND and Select All checkbox functionality.

## Steps

1. Navigate to Brand > Paid with MTV selected and a representative date range.
2. Open the Filter dropdown and select Tag sub-filter.
3. Verify default state: Include + Or operator + checkbox list + Select All option.
4. Add an Include tag with Or operator.
5. Switch to Exclude — confirm Include-selected tags greyed.
6. Add a different Exclude tag.
7. Test Or vs And on Include (≥2 tags).
8. Test Select All checkbox functionality.
9. Apply Filter; capture the URL `filters` JSON encoding.
10. Verify the page contents update with layered filter.
11. Clear All filters.
