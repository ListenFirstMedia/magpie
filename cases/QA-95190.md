# QA-95190 — Brand > Channels - Threads Basic View

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-95190
- **Priority:** Critical
- **Ingested:** 2026-07-13 from Jira (Xray custom fields)

## Preconditions
User should be logged in to Max

## Steps
1. Hover over the Brand dropdown and Click Channels
2. Click the Brand search dropdown and type and select 'Max' brand
3. Set the date range as from Dec 01, 2024 to Dec 01, 2024
4. Review the Threads tile data card
5. Click on 'Insights'
6. Click on 'Content'

## Assertions
3(a). Ensure the Perspective view is 'Authorized'
3(b). Ensure the Threads tile is displaying after the LinkedIn tile
4(a). Ensure the following metrics are displayed in the same order: Total Followers, New Followers, Fan Growth Rate, New Posts, Engagements, Engagements Rate, Views
4(b). Note the tile values
5(a). Ensure the page navigates to 'Brand Insights' with only Threads channel selected
5(b). Ensure the Big Number matches the metrics in the Threads channel tile
6. Ensure the page navigates to 'Brand Content' with only Threads channel selected
