## Description
This test case ensures the Native data check with LFM for Post Publish Type "Reels".

## Preconditions
User logged in as UCLA.

## Steps
1. Hover over Brand and Select Content from the Top Nav.
2. Type and select 'UCLA' brand.
3. Click the data set dropdown and Select 'Reels' Dataset.
4. Note Reel Reactions, Reel Comments and Reel Shares value from the first post.
5. Click the Video on the first post.
6. Note the Reel Likes, Reel Comments, and Reel Shares value from the native post.

## Assertions
- A1 (step 6): Ensure the LFM value of metrics should not have big variations when compared with Native (Facebook) values.
