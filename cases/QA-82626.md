## Steps
1. Reporting → Data Studio.
2. Add a Brand search.
3. Add Star Wars + MTV (Authorized).
4. Select Metrics: Facebook Total Fans, Twitter Total Followers (Followers section).
5. Click Go.
6. Click Pin icon (creates short link).
7. New tab → paste short link.
8. Click configuration button.
9. Trash icon next to Twitter Total Followers.
10. Click Go.

## Assertions
- A1 (step 8a): Short link matches previously opened page URL.
- A2 (step 8b): Same report displayed.
- A3 (step 9a): Same applied configurations on new page.
- A4 (step 9b): Go button disabled when no changes.
- A5 (step 10a): Go button enabled after change.
- A6 (step 11): New report generated with updated configuration.
