## Steps
1. Hover over the Brand and Select Content from the Top Nav  
2. Add a Brand and Select the Facebook Only Reactions dataset  
3.  In the Aggregate Table Add the values of Likes, Loves, Hahas, Wows, Sads, Angries, and Others for the sum and average  
4. Select the Facebook Only: Completed and Live Video  dataset  
5. In the Aggregate Table Add the values of Organic Completed Views and Paid Completed Views for the sum and average  
6. Select 'Twitter Only: Engagements & Follows' Breakdown Data Set  
7. In the Aggregate Table Add the values of Paid User Follows,  and Organic User Follows for the sum and average  
8. Select Instagram Only: Insights Data Set  
9. In the Aggregate Table Add the values of Organic Saves, and Paid Saves for the sum and average  
10. Select YouTube Only: Insights Data Set  
11. In the Aggregate Table Add the values of Organic Views, Paid Views and Unclassified Views for the sum and average  
12. In the Aggregate Table Add the values of Organic Watch Time (Minutes) and Paid Watch Time (Minutes) for the sum and average  
13. Select YouTube Only: Premium Dataset  
14. In the Aggregate Table Add the values of Organic Premium Views and Paid Premium Views for the sum and average  
15. In the Aggregate Table Add the values of Organic Premium Watch Time (Minutes) + Paid Premium Watch Time (Minutes) for the sum and average

## Assertions
3. Ensure the sum value should be equal to the Reactions values.
