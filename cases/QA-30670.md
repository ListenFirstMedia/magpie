# QA-30670 — Brand Insights - Cross- Channel  Public Video Views Tile - Data QA

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-30670
- **Priority:** n/a
- **Ingested:** 2026-10-20 from Jira (Xray custom fields), Test Set QA-26183 "Daily Data Testing -2"

## Description
This test case ensures that the brand insights Public video views data match the channel-specific sums

## Preconditions
* User logged in as Viacom

## Steps
1. Hover over the Brand from Top Nav Select Insights  
2. Add MTV Brand and Select Public Data View  
3. Select Facebook, Twitter Instagram and TikTok Channels  
4. Note the Public Video Views value on Public Video Views Tile  
5. Hover over the Reporting from Top Nav Select Classic Reporting  
6. Select TWC Template  
7. Add MTV Brand (Public Data)  
8. Select Absolute Date and Interval as an "Aggregate"  
9. Click By Channel on data Section  
10. Select [ Facebook Public Video Views, Twitter Public Video Views, Instagram Public Video Views & TikTok Public Video Views]  
11. Deselect the Show Metrics Graphs Option  
12. Run a Report and sum the all channel's public video views value

## Assertions
12. Ensure the brand Insights Cross Channel Public Video Views Values should be Equal to the Sum of the Public Video Views value of the TWC Report
