# QA-88219 — Dashboards - Brand Content - Functionality to save filtered tiles to the dashboard

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-88219
- **Priority:** P? (Mutation flow)
- **Description (from Jira):** Verifies the functionality of saving filter tiles to the dashboard.
- **Type:** MUTATING — cleanup non-optional. Unique tag: `qa-88219-rerun-<DATETIME>`.

## Preconditions
- User logged in (Adam Orfei dev).
- Brand with content data (MTV / Hulu).
- Existing dashboard OR create new dashboard for cleanup-friendly run.

## Steps
1. Brand → Content for the test brand. Apply a filter (e.g., Publish Type = Photo OR a Tag filter — anything that visibly narrows the tile data).
2. Locate a tile that supports `Save to Dashboard` (or use page-level Save).
3. Click `Save to Dashboard`. Modal opens — pick or create a destination dashboard.
4. Confirm save. Dashboard receives the filtered tile with filter context preserved (likely a Saved Filter Context badge or the filter values rendered on the tile).
5. Navigate to the destination dashboard. Verify the tile renders the SAME filtered data as on Brand > Content (numerics + filter chip both visible).
6. CLEANUP: delete the saved tile from the dashboard (and the dashboard if newly created).

## Assertions
- A1: Save to Dashboard control is present and clickable on at least one Brand > Content tile.
- A2: Save modal opens.
- A3: Save completes (modal closes; success toast or tile appears on dashboard).
- A4: Dashboard tile renders with filter applied (numerics match Brand > Content).
- A5: Cleanup — tile deleted, no orphan.
