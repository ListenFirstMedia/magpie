## Objective

Verify that on the Brandsets > Content page (`#explore/competitive/content`), users can simultaneously Include and Exclude tags in the same filter set (layered tag filtering), mirroring the behavior delivered for Brand > Content.

## Steps

1. Navigate to Brand Sets > Content (`#explore/competitive/content`) with Adam's Brand Set selected.
2. Open the Filter dropdown and select the Tag sub-filter.
3. Confirm the Tag popup defaults to Include with Or/And operator radios and tag-value checkboxes.
4. Add a tag to Include with operator = Or.
5. Switch to Exclude — confirm Include-selected tags become disabled/greyed.
6. Add a different tag to Exclude.
7. Apply Filter and observe the URL `filters` JSON encoding and the resulting Posts count change.
8. Verify the Sum/Avg row + Posts table populate correctly.
9. Test Or-vs-And operator on Include with multiple tags.
10. Clear All filters.
