# QA-133403 — Brand Set > Content - Verify Authorised Video Views Metrics Sum and Avg Row Behavior

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-133403
- **Priority:** Major (P3)
- **Description:** Verify Sum and Avg rows display correctly for all metrics based on brand authorization status (Authorized Only, Unauthorized Only, Mixed Brands), including post count accuracy, data loading, export validation, and filter interactions.

## Preconditions
- User logged in as Viacom
- Brand Set: 2019 BET Awards Sponsors (mix of authorized + unauthorized brands)
- Date Range: March 23, 2026 – March 24, 2026
- Mode: Lifetime

## Steps
1. Click Brand Sets → Content
2. Select 2019 BET Awards Sponsors
3. Set date range Mar 23 2026 – Mar 24 2026
4. Select Grid View icon
5. Click Rank by dropdown
6. Select Video Views under Authorised Data section
7. Apply Filter: Content Publish Type = Reel
8. Click Export → CSV with current data sets
9. Remove the above filter; Apply Filter: Content Brand = McDonald's
10. Click Export → CSV with current data sets

## Assertions
- A1 (6a): Post count updates after selecting Video Views
- A2 (6b): Correct channels displayed for Video Views: Facebook, Twitter, Instagram, YouTube, TikTok
- A3 (6c): Sum and Avg rows display calculated Video Views values (not endash) or N/A
- A4 (7a): No endash (–) or N/A in Sum or Avg
- A5 (7b): Post count matches number of posts with actual data (excluding endash/lock)
- A6 (7c): Avg row = Sum ÷ posts with data
- A7 (8a): CSV data matches UI data
- A8 (8b): Exported CSV does NOT contain Sum/Avg rows
- A9 (9a): Only McDonald's posts displayed after Content Brand filter
- A10 (9b): Lock icon on Instagram and Facebook posts for Video Views / Shares where unauthorized
- A11 (9c): Video Views and Shares values visible for posts on other channels (non IG/FB)
- A12 (9d): Sum and Avg rows display correct values for Video Views
- A13 (9e): Post count matches posts with actual data (excluding endash/lock)
- A14 (10a): CSV data matches UI data
- A15 (10b): Exported CSV does NOT contain Sum/Avg rows
- **Data accuracy:** Sum value = total of all individual post Video Views values (for posts with data)

## Notes
- Brand Set "2019 BET Awards Sponsors" requires Viacom account context. If Adam Orfei surfaces "Adam's Brand Set" (76K posts) instead, account-switch is required; if not feasible, pre-narrow + brand-set substitute is allowed per known-quirks.
- View toggle on Brand Sets > Content is DISABLED at brand-set level; Authorized perspective inferred by picking a metric from the "Authorised Data" subsection in Rank-by dropdown (per known-quirks 2026-06-02).
