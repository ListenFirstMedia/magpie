## Preconditions
- User logged in as Adam Orfei

## Steps
1. Settings → Custom Metrics
2. Click Create a Custom Metric
3. Name: `Automation - All Operators Metric`
4. Description: `Plus minus mult div coverage`
5. Click Formula input
6. Metrics → Facebook → Post Comments
7. Operators → `+`
8. Metrics → Facebook → Post Likes
9. Operators → `−`
10. Metrics → ListenFirst → Shares
11. Operators → `×`
12. Constants → type `2`, confirm
13. Operators → `÷`
14. Constants → type `100`, confirm
15. Save → enabled → click
16. Success popup → OK
17. Reporting → Time Window Comparison
18. Add Brand → `MTV` → MTV(authorized)
19. Add Metric → Custom → select created metric
20. Run report
21. Wait for results table

- 14-A: Operators dropdown exposes `+`, `−`, `×`, `÷` (4 options)
- 14-B: Formula row order = [Post Comments, +, Post Likes, −, Shares, ×, 2, ÷, 100] (9 chips)
- 15: Save enabled before click
- 16-A: Success popup = "Custom metric successfully created!"
- 16-B: Listing contains `Automation - All Operators Metric`
- 19: TWC metric picker returns Custom result `Automation - All Operators Metric`
- 21-A: Results table visible with column header `Automation - All Operators Metric`
- 21-B: Metric value cell for `MTV` is a calculated numeric value
