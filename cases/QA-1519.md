## Preconditions
User logged in as Hulu.

## Steps
1. Click Brand (top nav) → Content tab.
2. Brand dropdown → Type "Hulu".
3. Select Hulu Brand from list.
4. Click Table View.
5. Data set dropdown → Select "Engagement Breakdown".
6. Click Export button.
7. Select all data sets in export popup → click OK.
8. Open email → download attached CSV.
9. Export → toggle to Google Sheet.
10. Click OK in popup.
11. Open email → open attached Google Sheet.
12. Data set dropdown → Select "Clicks".
13. Click Export dropdown.
14. Click OK in popup.
15. Open email → download CSV.
