# QA-32750 — Brand Paid vs TWC > Big Numbers Data QA > Facebook

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-32750
- **Priority:** n/a
- **Ingested:** 2026-10-20 from Jira (Xray custom fields), Test Set QA-26183 "Daily Data Testing -2"

## Description
This Test Case ensures the Big number values between TWC and Brand Paid Tabs

## Preconditions
* User Should Logged In as Michael Kors

## Steps
1. Hover Over the Brand from Top Nav and Select Paid  
2. Add Michael Kors Brand  
3. Enable Facebook Channel Only  
4. Note the Following Big Number Values [Paid Impressions, Spend, Clicks, Paid Actions, 95% Completed Video Views]  
5. Hover Over the Reporting from Top Nav and Select Classic Reporting  
6. Select TWC Template  
7. Add Michael Kors Brand (Authorized)  
8. Select Absolute Dates and Aggregate them as an Interval  
9. In the Data Selection section Select By Channel   
10. Select the Following Facebook metrics [Ad Clicks, Paid Actions, Ad Impressions, Ad 95% Completed Views, Ad Spend]   
11. Deselect "Show Metrics Graphs" option  
12. Click Run Report  
13. Compare the values now

## Assertions
13. Ensure the Paid Page Big Number Values should be matched with the TWC Report values
