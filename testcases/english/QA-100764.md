# QA-100764 — Brand > Content - Daily Post Analysis Modal - Threads

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-100764
- **Priority:** Critical (P2)
- **Description:** Ensures the Graph Display & Behavior of the Daily Analysis Modal on the Brand Content Page for the Threads channel.

## Preconditions
- User should be logged in as Max

## Steps
1. Click Brand in the top nav and click Content in the dropdown
2. Click the Brand dropdown, Type and select 'Max' brand from the list
3. Enable Threads channel only
4. Click the 'Daily Analysis' button displayed below the first post
5. Click the Data Viz dropdown below the graph chart and select the 'Area' option
6. Click the 'Close' button

## Assertions
- A1 (step 4): Ensure the Threads channel icon is displaying in the right-side corner of the post
- A2 (step 4): Ensure the Graph header and the post header are displayed the header as the Brand name "Max"
- A3 (step 4): Ensure the X-axis is displaying the date range and the Y-axis is displaying the metric values
- A4 (step 4): Ensure No metrics are highlighted in the post
- A5 (step 5): Ensure the area chart is updated in the graph chart
- A6 (step 6): The window closes.
