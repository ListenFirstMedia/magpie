# QA-129606 — Handle Abnormally High Response Rate – Exclude Days Without Follower for Tiktok and Twitter

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-129606
- **Priority:** Blocker (P1)
- **Description:** Ensures Response Rate calculation excludes days where follower (footprint) data does not exist, even if engagement data is present for Twitter and Tiktok on Daily basis.

## Preconditions
- User logged in as Wasserman

## Steps
1. Reporting → Time Window Comparison
2. Add brand "FIA World Endurance Championship (FIAWEC)"
3. Absolute Date Range, interval Days
4. Date range: Sep 26 – Oct 3, 2025
5. By Channel → select Twitter (then run separately for TikTok)
6. Metrics: Audience & Growth > Total Followers; Content > Engagements, Posts, Response Rate
7. Click Run Report
8. Review Report
9. Export → Google Sheets

## Assertions
- A1 (step 8): Report loads successfully with no errors
- A2 (step 10): Engagements data displayed same on UI and Google Sheet
- A3 (step 10): Total Followers data displayed same only for days where it exists
- A4 (step 10): Response Rate data same and only for days where Total Followers exists
- A5 (step 10): Day-wise Response Rate = Engagements / (Total Followers × Posts) × 100, matches UI and Google Sheet
