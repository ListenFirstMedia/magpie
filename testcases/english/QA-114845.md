# QA-114845 — Brand > Insights - Hovering functionality and PNG Export

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-114845
- **Priority:** Minor
- **Description:** Ensures the Total Followers and Fan Growth Rate big-number functionality on Brand > Insights.

## Preconditions
- User logged in as Michael Kors.

## Steps
1. Click Brand in the top nav and click Insights.
2. Search and select the 'Michael Kors' brand.
3. Hover the Total Followers pie chart.
4. Click on Export dropdown and select 'PNG'.
5. Hover on the Fan Growth Rate.
6. Click on the Export dropdown and select 'PNG'.

## Assertions
- A3 (step 3): Tooltip displays as "Channel name: value".
- A4a (step 4): File name should be Brand-Tab-Tile-Pie-YYYY-MM-DD(Start)-YYYY-MM-DD(End).png.
- A4b (step 4): PNG matches with the page.
- A5 (step 5): Values should be `Mon. DD, YYYY` + `Fan Growth Rate: value`.
- A6 (step 6): File name should be Brand-Tab-Tile-Bar-YYYY-MM-DD(Start)-YYYY-MM-DD(End).png.

## Notes
- Last 30 Days window to avoid Brand>Insights renderer freeze (known-quirks).
