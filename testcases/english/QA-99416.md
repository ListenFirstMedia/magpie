# QA-99416 — Brand Sets > Content - Daily Post Analysis Modal - Table Display & Behavior

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-99416
- **Description:** Ensure the Table display & behavior of the Daily Analysis Modal in the Brand Sets > Content page.

## Preconditions
- User logged in.
- Brand Set with multi-brand content data.

## Steps
1. Navigate to Brand Sets > Content for an existing brand set.
2. Pick a date range with daily data (Last 30 Days or similar).
3. Open a Daily Post Analysis surface that triggers the Daily Analysis Modal.
4. Switch view to Table within the modal.
5. Verify columns include Date + per-metric columns + Total / Sum row if applicable.
6. Verify each row corresponds to a day in range and values match what underlying data set returns.
7. Switch metric / channel toggle; verify table repopulates.
8. Watch for endash on TikTok rows (DATA-12209) on suspect dates.

## Assertions
- A1: Modal opens with Table view option.
- A2: Table columns match metric / date schema.
- A3: Row count matches days in range.
- A4: Switching metric repopulates table.
- A5: Endash markers only appear on documented data gaps.
