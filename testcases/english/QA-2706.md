# QA-2706 — Brand > Content - Benchmark - Authorized

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-2706
- **Priority:** Blocker (P1)
- **Description:** Ensures the Detail view of the content benchmark.

## Preconditions
- User logged in as Amazon Prime Video

## Steps
1. Click Brand > Content
2. Select brand 'Amazon Prime Video'
3. Click the Benchmark button
4. In the collection dropdown, Type and Select 'Set to Current Brand'
5. In the Benchmark Period dropdown, Type and Select Rolling 7 Days
6. Click Go button

## Assertions (all at step 6)
- A1: Benchmark percentage indicators are only updated on Average aggregate row in the Aggregate table
- A2: Benchmark Row displays benchmark value for each metric in its corresponding column, below Sum and Average values; if no data, values should display N/A
- A3: Each post metric in the post contains Benchmark values; if no data, values should display N/A
- A4: Collection breadcrumb displays the benchmark used
- A5: Metrics for each post shows percentage indicators values based on the comparison to the benchmark
- A6: Post metric percentage values should be rounded to the nearest percent
