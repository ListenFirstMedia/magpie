# QA-132392 — Brand Set > Content - Verify Impression Metrics Sum and Avg Row Behavior

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-132392
- **Priority:** Critical (P2)
- **Description:** Verify Sum and Avg rows display correctly for Impression metric across Authorized/Unauthorized/Mixed brand-set states; post count accuracy, data loading, export validation, filter interactions.

## Preconditions
- User logged in as Adam Orfei
- Brand Set: Adam's Brand Set (mix of authorized + unauthorized brands)
- Date Range: Last 30 days
- Mode: Lifetime (default)

## Steps
1. Brand Sets → Content
2. Select Adam's Brand Set
3. Date Range = Last 30 Days
4. Detail view icon
5. Click Rank by dropdown
6. Select Impression under Authorised Data
7. Apply filter: Content Brand = MTV
8. Export → CSV (current data sets)
9. Remove filter; apply Content Brand = NBA
10. Export → CSV (current data sets)

## Assertions
- A1 (6a): Sum and Avg values updated
- A2 (6b): Post count updated
- A3 (6c): Correct channels for Impressions: Facebook, Twitter, Instagram, TikTok
- A4 (6d): Sum/Avg show calculated values or N/A (no endash)
- A5 (7a): No endash or N/A in Sum/Avg
- A6 (7b): Avg row = Sum ÷ number of posts with data
- A7 (8a): CSV matches UI
- A8 (8b): CSV does NOT contain Sum and Avg rows
- A9 (9a): Only NBA posts displayed
- A10 (9b): Lock symbol visible on posts where applicable
- A11 (9c): Lock symbol on posts where Impressions unavailable due to authorization
- A12 (9d): Sum/Avg rows display endash (–) for Impression when no data
- A13 (9e): Post count matches posts with actual data (excluding endash posts)
- A14 (10a): CSV matches UI
- A15 (10b): CSV no Sum/Avg rows

**Data accuracy:** Sum = total of all individual post Impression values for posts with data.
