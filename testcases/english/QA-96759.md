## Description

The Test case ensure the Threads - Tile Export - PNG

## Preconditions
- Logged in as the test user
- Brand with Threads data identity available

## Steps
1. Navigate to Brand > Insights with Threads channel selected
2. For each tile on the Insights page, open the tile-level Export dropdown
3. Click Export → PNG
4. Verify PNG file downloads to disk
5. Verify filename schema matches `<Brand>-Insights-<Tile>-<ChartType>-<from>-<to>.png`

## Assertions
- PNG export available on every Threads Insights tile
- File saved on disk with correct filename schema and non-empty content
