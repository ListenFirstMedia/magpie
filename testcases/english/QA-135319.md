# QA-135319 — Brand > Content - Verify default selections, Include/Exclude interaction, and filter removal behavior

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-135319
- **Priority:** Critical (P2)
- **Description:** Verifies Tag filter defaults, Include/Exclude toggle behavior, pill display (green/red), and confirms removing an unapplied pill has no impact on page results.

## Preconditions
- User logged in as HULU
- 3-4 posts tagged (add+cleanup if needed)

## Steps
1. Go to Brand > Content
2. Select HULU brand
3. Open Filter dropdown
4. Choose Tag filter
5. Look at how the filter looks before adding any tag
6. Select Exclude radio button
7. Select INCLUDE radio button again
8. Select any TAG_1 tag as INCLUDE
9. Select a second TAG_2 tag as EXCLUDE
10. Hover on EXCLUDE Pill and REMOVE it
11. Observe behavior

## Assertions
- A1 (step 5a): Include selected by default; Exclude not selected
- A2 (step 5b): OR selected by default but disabled until >1 tag selected
- A3 (step 5c): User cannot select AND until ≥2 tags selected
- A4 (step 6): Exclude now selected; Include unselected
- A5 (step 7): Include selected again; Exclude unselected; smooth toggle
- A6 (step 8a): Include remains selected by default; Exclude not selected
- A7 (step 8b): OR remains selected by default; AND not selected
- A8 (step 8c): Green filter pill for TAG_1 (Include) visible in active filters bar
- A9 (step 9): TAG_2 visible as red filter pill (Exclude) in active filters bar
- A10 (step 11): Removing Exclude filter does not impact page or results (not yet applied)
