# QA-104870 — Settings > Custom Data Sets - Basic View

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-104870
- **Priority:** Blocker (P1)
- **Description:** Ensures a basic view of the 'Custom Data Sets' tab under the settings section.

## Preconditions
- The user should be logged in as Adam Orfei

## Steps
1. Hover over 'Settings' in the top nav
2. Click 'Custom Data Sets' in the dropdown
3. Click the Ellipsis Button in the first row of the Action column in the custom Data Set listing table
4. Review the Data Set listing table

## Assertions
- A1 (step 2): Ensure that the 'Custom Data Sets' option appears after 'Brands' in the settings dropdown.
- A2 (step 2): Ensure the 'Custom Data Sets' is selected in the dropdown
- A3 (step 2): Ensure the breadcrumb text 'Account: Adam Orfei | Settings > Custom Data Sets' is displayed above the Custom Data Sets Header.
- A4 (step 2): Ensure that when clicking on Custom Data Sets, the Data Sets Listing Screen opens, and displays the available Custom Data Sets.
- A5 (step 2): Ensure that when no Custom Data Sets have been created, a blank table is displayed.
- A6 (step 2): Ensure that the following text displays below the Custom Data Sets dropdown "Configure up to 10 Data Sets for your account with up to 7 metrics in each Custom Data Set"
- A7 (step 2): Ensure that the "Create a Custom Data Set" button is displayed on the right side of the window.
- A8 (step 2): Verify that the Custom Data Set listing table has the following fields: Data Set, Created Date, Creator, Metrics, and Actions.
- A9 (step 3): Ensure that the following options are displayed in order when clicking the ellipsis button: Edit, Delete, Duplicate
- A10 (step 4): Ensure the 'Data Set Name' is displayed under the 'Data Set' column.
- A11 (step 4): Ensure the 'Created Date' column displays the dataset creation date in the following format: Mon. DD, YYYY.
- A12 (step 4): Ensure the dataset creator's name is displayed under the 'Creator' column.
- A13 (step 4): Ensure the dataset's metrics are displayed under the 'Metrics' column, separated by comma.
