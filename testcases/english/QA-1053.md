# QA-1053 — TWC Aggregate - Relative dates - Lock icon and Endash

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-1053
- **Priority:** Critical (P2)
- **Description:** Ensure Lock icon and endash correctly display for TWC Aggregate Days interval.

## Preconditions
- User logged in as Hulu

## Steps
1. Reporting → Time Window Comparison
2. Interval dropdown → Aggregate
3. Type 5 between Start and Days
4. Add brand Hulu
5. Key date Jan 01, 2024
6. Add brand Full Frontal with Samantha Bee
7. Key date Jan 01, 2024
8. Add brand Snowfall
9. Key date Jan 01, 2024
10. Click Use Authorized Data
11. Data points: Instagram Comments, TikTok Total Followers
12. Run Report

## Assertions (step 12)
- A1: Snowfall displays en-dash in TikTok Total Followers Graph and Table
- A2: Full Frontal with Samantha Bee and Snowfall display lock for Instagram Comments in Graph and Table
- A3: Data displays for Full Frontal with Samantha Bee and Hulu for TikTok Total Followers
