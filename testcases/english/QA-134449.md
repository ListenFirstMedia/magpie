# QA-134449 — Brandsets > Optimization - Verify layered tag filtering (Include + Exclude)

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134449
- **Priority:** Critical (P2)
- **Description:** Verify Brandsets > Optimization supports simultaneous Include + Exclude tag filtering.

## Preconditions
- User logged in with HBO Max access; tags pre-applied to posts

## Steps
1. Brandsets > Optimization
2. Account HBO Max; Brandset LF // TV // EPISODIC
3. Date range 1/1/2026 – 1/7/2026
4. Open Tag Filter panel
5. Add tag to Include
6. Attempt same tag to Exclude
7. Add another tag to Exclude
8. Toggle OR/AND
9. Apply filters
10. Add another tag to Include or Exclude with OR/AND; Apply
11. Clear All
12. Re-add same tags to Include/Exclude, remove only Exclude
13. Save layered filter, reload, reopen with saved filter
14. Export Optimization tiles/data as CSV (and PNG where applicable)

## Assertions
- A1 (4): Tag Filter panel opens with Include+Exclude empty
- A2 (5): Include tag refreshes tiles to matching posts only
- A3 (6): Same tag greyed in Exclude
- A4 (7): Exclude refreshes to Include AND NOT Exclude
- A5 (8): OR/AND enabled after tag selected
- A6 (9): BPC Posts updated
- A7 (10): OR shows posts matching any/both; AND shows posts matching both
- A8 (11): Clear All empties both, restores unfiltered view
- A9 (12): Removing only Exclude returns Include-only set; Include persists
- A10 (13): Saved filter persists after reload
- A11 (14): Export contains only filtered rows
