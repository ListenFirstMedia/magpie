## Preconditions
Logged in as Disney Ad Sales.

## Steps
1. Click Brand → Content.
2. Brand dropdown → type Disney Channel, select.
3. Data Set dropdown → select Impressions.
4. Click Export.
5. Click Ok in export popup.
6. Hover Notification icon in top nav.
7. Click Download file hyperlink in notification.

## Assertions
- A1 (6a): Select Data Sets Export notification shows:
  - First row: `Mon DD, YYYY`
  - Second row: `Your Content Export with Select Data Sets for Brand Name from Mon. DD, YYYY to Mon. DD, YYYY is now ready. Download file.`
- A2 (6b): `Download file` text is blue hyperlinked.
- A3 (7): CSV file is downloaded.
