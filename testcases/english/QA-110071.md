## Description
Test the Metrics export from the Threads channel under Brand > Audience.

*(Jira description says "Instagram Audience Tab" but steps say Threads — treating Threads as the intent per case title and steps.)*

## Steps
1. Click **Brand** in the top nav and select **Audience**.
2. Type and select **MTV** brand from the list.
3. Select **Threads** channel only and set date range to **Mar 16, 2025 – Mar 22, 2025**.
4. Click the **Export** button and click the **Metrics** option.
