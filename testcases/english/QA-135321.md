# QA-135321 — Brand > Content - Verify Additional filter working with tag filter

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-135321
- **Priority:** Critical (P2)
- **Description:** Verify Tag filter works correctly in combination with another filter. Multiple filters apply together; page results reflect combined criteria.

## Preconditions
- User logged in as HULU
- At least 3-4 posts have tags (add and clean up if needed)

## Steps
1. Go to Brand > Content page
2. Select HULU brand
3. Open the Filter dropdown
4. Choose Tag filter
5. Select any TAG_1 tag as INCLUDE
6. Select a second TAG_2 tag as EXCLUDE
7. Apply filter
8. Click on filter and select Paid option
9. Select Boosted from paid popup
10. Click Apply

## Assertions
- A1 (step 5): Include Tag added with green filter pill for TAG_1
- A2 (step 6): TAG_2 visible as red filter pill (Exclude) in active filters bar
- A3 (step 7): Filter impacts page data
- A4 (step 10): Both tag and Paid filters implemented
