# QA-27854 — Bulk Import Tags Notification

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-27854
- **Priority:** Minor (P4)
- **Description:** Ensure the bulk import tags Notifications display correctly in-app and via email.

## Preconditions
- User logged in as Adam Orfei
- Successfully completed QA-27290 (a prior bulk-tag upload)

## Steps
1. Hover over the Bell icon
2. Hover over the settings tab and click Notifications
3. Open Bulk Tagging mail in a new tab
4. Review the message

## Assertions
- A1 (step 1): Import Tags Notification displays in the bell dropdown
  - Header: "Import Tags"
  - Subheader: file Updated Date and time in format MMM DD.HH:MM AM/PM
  - Message: "filename.csv" has been successfully uploaded. For details, please download detail log.
  - "download detail log" text is hyperlinked
- A2 (step 2): Import tags notification displayed in the Notifications table; New Status appears blank
- A3 (step 4 - Success): Email message matches:
  ```
  Hi [User],
  You're all Set!
  The Tags you uploaded with [File Name] at [time] have successfully been uploaded at [time]
  (No. of) tags were successfully uploaded.
  ```
- A4 (step 4 - Failure, if applicable): Email message matches:
  ```
  Hi [User],
  So Close!
  Looks like there was something funky happening with the [File Name] Bulk upload.
  (No. of) tags were successfully uploaded, and (No. of) tags failed to upload.
  Check out where the job went wrong by downloading Detail Log in this email or in Notifications.
  ```
