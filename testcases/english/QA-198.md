# QA-198 — TWC Exports - Absolute dates

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-198
- **Priority:** Critical (P2)
- **Description:** User can export TWC report to TSV, CSV, XLS, Google Sheets.

## Preconditions
- User logged in as Disney Ad Sales

## Steps
1. Reporting → Time Window Comparison
2. Select Absolute dates
3. Add 4 brands: Disney Channel, CBS News, CNN, Fox News
4. Add data points: Instagram Follower Growth Rate (rate), New Followers, Facebook New Fans
5. Run Report
6. Export → CSV
7. Export → TSV
8. Export → XLS
9. Export → Google Sheets

## Assertions
- A1 (step 6): Export to Google Sheets, TSV, CSV, XLS options available
- A2 (step 7): Brands and data points in same order as report screen
- A3 (step 7): Only selected datapoints displayed
- A4 (step 7): Dates match report
- A5 (step 7): Rate % displays as float value
- A6 (step 7): En-dash not displayed in export
- A7 (step 7): Exports match TWC report
- A8 (step 8): TSV data matches CSV
- A9 (step 9): XLS data matches CSV
- A10 (step 10): Google Sheets data matches CSV
