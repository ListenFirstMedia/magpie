# QA-111242 — Brand > Content - Sentiment - Read comments CSV Export and notification pop-up

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-111242
- **Priority:** Critical (P2)
- **Description:** Verifies CSV export of the Read Comments modal triggered from Sentiment on Brand > Content, plus the notification popup.

## Preconditions
- User logged in on a brand with sentiment-tagged posts on multiple channels (MTV is the bug-target; also try Adam Orfei / Hulu non-IG for control).

## Steps
1. Brand → Content (MTV).
2. Set date range to a recent week (e.g., last 7 days).
3. Filter to Instagram channel.
4. Click Sentiment button.
5. Click Read Comments on an IG post (probe target).
6. Observe whether comments load; capture the notification popup if shown.
7. Click Export → CSV.
8. Click OK on Sentiment Export Request popup.
9. Switch channel to a non-IG channel (e.g., Twitter or Facebook) — repeat steps 5-8.

## Assertions
- A1 (step 5 IG): Read Comments modal displays comments — probe LFMP-31947 (MTV IG known bad).
- A2 (step 6): Notification popup shows "2,000 Sample Comments..." message or sentiment-limit messaging.
- A3 (step 8): CSV export request submitted, notification confirms.
- A4: Resulting CSV in Downloads contains rows + matches modal where applicable.
- A5 (control, non-IG): Read Comments displays correctly on a non-IG channel.

## Probes (open bugs)
- LFMP-31947 (Major) — Brand content Sentiment Read Comments not displaying for IG channel (MTV).
