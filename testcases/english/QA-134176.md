- **Description:** Verify Auto-Select Dates dropdown options for Daily / Weekly / Monthly / Quarterly intervals on Brand > Insights Date Range selector.

## Preconditions
- User logged in as Sephora (sub for Adam Orfei context if needed — Sephora brand_id=29, account_id=54)

1. Click Brand top navigation
2. Select Insights
3. Select Date Range option

8. Click Interval Dropdown and Select Monthly
