# QA-111243 — Brand > Content - Sentiment - Emotion (Daily) - CSV Export Email Format

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-111243
- **Priority:** standard
- **Description:** Verifies the email format validation when downloading Sentiment Comments data from the donut/emotion (daily) chart.

## Preconditions
- User logged in on a brand with sentiment-tagged posts.
- Brand → Content → Sentiment mode ON.

## Steps
1. Brand → Content (e.g., Hulu).
2. Set date range to last 7 days.
3. Channel filter Instagram (or whatever has sentiment data).
4. Click Sentiment button.
5. Scroll to Emotion (Daily) donut/stacked chart.
6. Click Read Comments / Read on a slice (e.g., Joy or Anger).
7. In modal → Export → CSV.
8. Confirmation popup appears prompting email or message.
9. Click OK.
10. Wait for export email / CDN-queued CSV.
11. Verify CSV row count vs modal sample count.

## Assertions
- A1: Read Comments modal opens for selected slice / day.
- A2: Export CSV triggers a confirmation popup with email-format message.
- A3: Notification bell / Recent Activity shows export entry with correct title.
- A4: CSV file downloads or arrives via the configured email.
- A5: CSV column headers present (Date, Author, Comment Text, Classified, Emotion, Topics, etc.).
- A6 (probe APPS-55875): CSV row count vs modal count should match (Hulu: 323 vs 319 known mismatch ≤4).

## Probes (open bugs)
- APPS-55875 (Minor) — Brand content - Sentiment Read Comments exported data mismatched with comments modal (Hulu - 323 in modal vs 319 in export).
