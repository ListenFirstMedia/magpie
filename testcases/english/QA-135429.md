## Objective

Verify Edit functionality on a Custom Metric: ellipsis → Edit opens the metric in the same builder UI prefilled with current values; user can modify name/description/formula and save; the row updates persistently.

## Steps

1. Navigate to Settings > Custom Metrics.
2. Pick an existing metric (ideally a sandbox/test metric) — open ellipsis Actions → Edit.
3. Verify Edit page opens with all fields prefilled (name, description, formula).
4. Modify a field (e.g., description).
5. Save.
6. Confirm row reflects edited values on the list.
7. F5 refresh — edit persists.
