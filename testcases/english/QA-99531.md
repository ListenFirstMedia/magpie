## Description

This test case ensures the hover functionality of the Threads channel on the Performance by Channel and Content Insights tiles, and verifies that it matches the chart and table data.

## Preconditions
- Logged in as the test user
- Brand with Threads data identity available

## Steps
1. Navigate to Brand > Content with Threads channel selected
2. Hover the Performance by Channel tile area
3. Verify tooltip renders with Threads metric values
4. Hover each Content Insights tile chart
5. Verify hover tooltip values match Posts table / Insights numerics

## Assertions
- Hover tooltips render for Performance by Channel + every Insights tile
- Hover values match underlying Posts/Insights data
