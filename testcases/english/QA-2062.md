## Preconditions
User is logged into the platform. A brand with Pinterest channel data is accessible (Sephora is canonical from QA-929).

## Steps
1. Click Brand top nav, select Content
2. Type and select 'Sephora' in the brand dropdown
3. Select 'Pinterest' channel only
4. Set the Data Set dropdown to 'Pinterest Only: Basic' (Public/default may show Posts (0))
5. Switch layout to Table view
6. Hover over the Type column icon (or post image cell) for the first Pinterest row
7. Observe the embedded Pinterest pin tooltip / preview
8. Repeat hovering for additional rows

## Assertions
A1. Hovering the Pinterest row's Type column opens an embedded tooltip showing the pin (image + caption + Published-by byline) for rows whose pin URL resolves on Pinterest's CDN.
A2. Tooltip has an X close control.
A3. Closing the tooltip restores the table state.
A4. Blank-tooltip rows (Pinterest CDN unavailable) are an expected external-platform behavior per known-quirks — flag as PARTIAL not FAIL.
