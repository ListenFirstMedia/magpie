# QA-75011 — Settings > Custom Metrics - Basic View

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-75011
- **Priority:** Blocker
- **Ingested:** 2026-07-09 from Jira (Xray custom fields)

## Preconditions
- The user should be logged in as Adam Orfei.

## Steps
1. Click 'Settings' in the top nav.
2. Click 'Custom Metrics' in the dropdown.
3. In the Search Custom Metrics search bar, enter the Metric name 'Cross-Channel Engagements'.
4. Click the Ellipsis Button in the first row of the Action column in the custom metric listing table.

## Assertions
1. Ensure that the Custom Metrics option appears next to Custom Data Sets in the settings dropdown.
2. Ensure the Custom Metrics is selected in the dropdown.
2. Ensure the breadcrumb text 'Settings > Custom Metrics' is displayed above the settings Header.
2. Ensure Search Custom Metrics with search bar displays above the Custom Metrics listing table.
2. Ensure that the placeholder text in Search Custom Metrics is 'Enter Custom Metric'.
2. Verify that the Custom Metrics listing table has the following fields: Metric, Description, Created Date, Creator, Formula, and Actions.
2. Ensure that the Creator and Formula columns are not empty.
2. Ensure that the 'Create a Custom Metric' button is displayed on the right side of the Custom Metrics page.
2. Ensure Help Center (fas fa-question-square) and Info view button (fas fa-info-circle) displays Top right side of the page with icons.
3. Ensure the Custom Metrics listing table is updated according to the Metric entered in the search bar.
4. Ensure that the following options are displayed in order when clicking the ellipsis button:
- Edit
- Delete
