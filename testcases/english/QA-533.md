## Preconditions
User logged in as **Viacom**.

## Description
Long post titles in the Brand > Content table should display ellipsis (`…`) and reveal the full text on hover via tooltip.

## Steps
1. Hover Brand in top nav → Content.
2. Click Brand dropdown.
3. Select **MTV** brand.
4. Click **Table view** in View mode.
5. Hover over a post text with ellipsis.
6. Click the post link.

## Assertions
- **A1 (step 4):** All column names display fully without being cut off.
- **A2 (step 5):** Full post text displays on hover (tooltip visible).
- **A3 (step 6):** Post text matches the tooltip content.
