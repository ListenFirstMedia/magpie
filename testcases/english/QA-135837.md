title: Verify search field retains entered value after selecting filter options
test_set: QA-22296

## Preconditions
- User logged in as HULU Account
- Tags test1, test11, and test123 or similar tags exist
- At least two collaborators with similar names exist

## Steps
1. Navigate to Brand > Content
2. Select the HULU brand
3. Open the Filter dropdown
4. Choose Tag filter
5. Type `test1` in the search field
6. Select `test1` from the results
7. Without retyping, select `test11` and `test123`
8. Deselect `test1`
9. Close and reopen the Tag filter dropdown
10. Repeat steps 3–7 for the Collaborator Name filter, using a value that matches multiple collaborators
11. Click Apply Filter

## Assertions
- 6a: Search field still displays `test1` after selecting `test1`
- 6b: `test1` appears selected in dropdown
- 7a: Search field still displays `test1` after selecting `test11` and `test123` without retyping
- 7b: `test1`, `test11`, `test123` all appear selected
- 8: Search field still displays `test1` after deselecting `test1`
- 9: Search field empty after closing and reopening dropdown; previously selected tags (test11, test123) remain selected
- 10: All 6a–8 hold for Collaborator Name filter
- 11: Applied filter returns content reflecting all selected tags + collaborators
