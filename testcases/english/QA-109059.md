## Preconditions
- User logged in as **Adam Orfei**.
- Successfully completed **QA-106218** (a Custom Data Set already exists).

## Description
Ensure the previously created Custom Data Set is correctly surfaced on the Brand > Content page.

## Steps
1. Click **Brand** and select **Content** in the dropdown.
2. Click the brand selector, type, and select **MTV**.
3. Click the **Data Set** dropdown and scroll down.
4. Click on the data set that was created on the Custom Data Sets page (per QA-106218).
5. Change the view to **Table View**.
6. Change to **Grid View** and click on the **All Metrics** container.
7. Unselect the **Engagements** metric.

## Assertions
- **A1 (step 3a):** "Custom Data Sets" section appears below the Channel-Specific metrics under a divider, with header text "Custom Data Set".
- **A2 (step 3b):** Custom data sets are displayed in creation order.
- **A3 (step 4a):** Channels appear in order: Facebook, Twitter, Instagram, YouTube, TikTok, LinkedIn, Threads, Pinterest *(crossed-out)*.
- **A4 (step 4b):** Pinterest channel appears after the divider in the channel container.
- **A5 (step 4c):** Only the selected metrics show on the page: Engagements, Reactions, Comments, Reactions, Shares, Engagement Rate, Impressions.
- **A6 (step 5):** Table view shows the same data as grid view.
- **A7 (step 6):** All Metrics container shows only the selected metrics.
- **A8 (step 7):** Unchecking Engagements removes it from the page.

## Notes
- Hard dependency on **QA-106218**. If no Custom Data Set exists for Adam Orfei, the test is blocked at step 4.
- The assertion list in Jira is numbered with duplicates (multiple "3.", "4.") — preserved here as A1..A8 for clarity.
- Pinterest appearing "crossed-out" likely means it's visually shown but disabled or strikethrough.
