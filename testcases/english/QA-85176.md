# QA-85176 — Settings > Custom Metrics - Custom Metric Create Functionality

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-85176
- **Priority:** Critical (P2)
- **Description:** Verify Custom Metric Creation includes all necessary elements (headers, input fields, button states, dropdown options, metric interactions).

## Preconditions
- User logged in as Adam Orfei

## Steps
1. Settings → Custom Metrics
2. Click 'Create a Custom Metric'
3. Enter unique name + description (e.g., Sample Metric)
4. Click Formula input field
5. Select 'Metrics' → Facebook channel
6. Type + select 'Post Comments'
7. Add '+' operator
8. Hover Metrics → ListenFirst channel → 'Shares'
9. Type + select '-' operator and 'Post Likes'
10. Click 'X' next to last added metric
11. Click 'X' next to last operator
12. Click Save
13. Click OK in Success popup

## Assertions
- A1 (2): Save button initially disabled
- A2 (4): Dropdown shows Metrics, Constants, Operators with Operators initially disabled
- A3 (5a): Hovering Metrics displays channels in order: ListenFirst, Facebook, Twitter, YouTube, Instagram, TikTok, Wikipedia
- A4 (5b): Hovering Facebook shows sub-dropdown with metrics (channel icon, metric name, DCR key)
- A5 (6a): Typing metric name shows matching options
- A6 (6b): Selecting metric adds it to formula row (channel icon + metric name only)
- A7 (7a): Selecting metric enables Operators, disables Metrics in Formula dropdown
- A8 (7b): + and - operators available
- A9 (7c): + operator added to formula row
- A10 (8): Hover ListenFirst shows up to 10 metrics with scroll bar
- A11 (10): Last metric removed from formula row
- A12 (11): Last operator removed from formula row
- A13 (12): Success popup displays "Custom metric successfully created!"
- A14 (13): Page refreshes, shows saved metric name on Custom Metrics page
