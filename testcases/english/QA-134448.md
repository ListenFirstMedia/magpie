# QA-134448 — Brandsets > Partnership - Verify layered tag filtering (Include + Exclude)

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134448
- **Priority:** Critical (P2)
- **Description:** Verify Brandsets > Partnership supports simultaneous Include + Exclude tag filtering.

## Preconditions
- User logged in with HBO Max access; tags pre-applied to posts

## Steps
1. Brandsets > Partnership
2. Account HBO Max; Brandset LF // TV // EPISODIC
3. Date range 1/1/2026 – 1/7/2026
4. Open Tag Filter panel
5. Add tag to Include
6. Attempt same tag to Exclude
7. Add another tag to Exclude
8. Toggle OR/AND
9. Apply filters
10. Add another tag to Include/Exclude with OR/AND; Apply
11. Clear All
12. Re-add same tags, remove only Exclude
13. Save layered filter, reload, reopen
14. Export Partnership data as CSV
