# QA-134272 — Brand > Content - Verify default state, Include OR/AND logic and same tag greyed out in opposite filter mode

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134272
- **Priority:** —
- **Description:** This test case ensures Include and OR are enabled only after a tag is added. It verifies OR returns posts matching any tag, AND (explicit only) returns posts matching all tags, and a tag in Include is greyed out in Exclude.

## Preconditions
- User logged in as Adam Orfei
- Brand with at least 2 tags

## Steps
1. Navigate to Brand > Content
2. Open Filter dropdown → Tag
3. Probe default state: Include radio selected, Exclude not; Or visually selected but disabled, And unselected disabled
4. Click 1st tag → green pill, Or/And remain disabled
5. Click 2nd tag → Or/And enable
6. Flip to Exclude radio
7. Verify the 2 tags from Include are greyed out (cannot be selected) in Exclude

## Assertions
- A1: Include selected by default; Exclude not
- A2: Or selected by default but disabled until ≥2 tags
- A3: And not selected, disabled
- A4: After 1 tag added (Include), Or/And still disabled
- A5: Green pill renders for selected tag
- A6: After 2nd tag, Or/And enabled
- A7: Or still visually selected by default after enablement
- A8: Switching to Exclude: Include=false, Exclude=true
- A9: Tags in Include greyed in Exclude (mutual-exclusivity)
- A10: Pill encodes operator + tags in URL `filters` JSON
