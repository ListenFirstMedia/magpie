# QA-94978 — Brand Audience - LinkedIn Channel - PNG Export Functionality

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-94978
- **Description:** This test case ensures the PNG export functionality on LinkedIn Audience Tab.

## Preconditions
- User logged in.
- Brand with LinkedIn data available (UCLA verified working).

## Steps
1. Navigate to a LinkedIn-data brand's Brand > Audience > LinkedIn page.
2. For each tile (Followers: Job Function, Industry, Seniority, Staff Count Range, Followers By Country, Followers By Region), open the tile-level Export dropdown.
3. Choose PNG. Confirm a PNG saves to Downloads with the expected filename.
4. Open each saved PNG and visually verify it represents the tile.

## Assertions
- A1: Per-tile Export dropdown exposes PNG.
- A2: PNG file actually downloads to disk.
- A3: Filename follows `<Brand>-Audience-<tile>-<start>-<end>.png` pattern.
- A4: PNG content matches the visible tile (chart / list).
- A5: APPS-58574 layout misalignment may be observed but does not block PNG export.
