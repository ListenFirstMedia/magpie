## Preconditions
User is logged in as Hulu. User has dev open in 1 browser and stage open in another.

## Steps
1. Click Brand top nav, select content on stage and dev
2. Type and select Hulu in the brand dropdown on dev and stage
3. Select Facebook channel only and click Apply
4. Click view data set drop down and select Impressions
5. On Stage click Impressions
6. Compare Impressions data
7. On dev content, click data set drop down
8. Select the Video views
9. On stage Content, click data set drop down and select video views
10. Compare video views data
11. Compare posts

## Assertions
8. Ensure the impressions data for posts in the dev date range match the data on stage for those posts
10. Ensure the video views data match between dev and stage
11. Ensure the number of posts for each view matches
