# QA-134182 — Brand > Insights - Verify Interval Date selector enforces historical date limits

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134182
- **Priority:** Critical (P2)
- **Description:** Verify Brand > Insights date range selector enforces correct historical date limits (boundaries, disabled arrows, max lookback) across Daily, Weekly, Quarterly. Monthly: incomplete-range extends to include partial months (TWC parity).

## Preconditions
- User logged in as Adam Orfei

## Steps & Assertions

### Phase A — Daily
1. Brand > Insights
2. Click Date Range
3. Daily default; review calendars → A1: no right arrow in end-date calendar (cannot go beyond current month); A2: only last 12 months selectable
4. Select Last 12 Months → A3: no right arrow in end date calendar
5. Click next on start-date calendar → A4: immediate next month displays
6. Click prev on end-date calendar → A5: immediate previous month displays

### Phase B — Weekly
7. Interval → Weekly; Last 52 Weeks
8. Review calendars → A6: no right arrow in end; A7: restricted to Weekly window
9. Click next on start → A8: immediate next month displays
10. Click prev on end → A9: immediate previous month displays

### Phase C — Quarterly
11. Interval → Quarterly; max available range
12. Review → A10: no right arrow in end; A11: restricted to Quarterly window
13. Click next start → A12: immediate next month displays
14. Click prev end → A13: immediate previous month displays

### Phase D — Monthly incomplete range
15. Interval → Monthly
16. Set Sep 15 – Dec 15 manually; Apply → A14: range accepted, no error
17. Observe chart X-axis → A15: shows Sep, Oct, Nov, Dec (extends to include partial start + end months per APPS-58615 backward+forward extension rule)
