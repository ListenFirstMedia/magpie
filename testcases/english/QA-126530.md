## Preconditions
User logged in as **Adam Orfei**.

## Description
When the user selects "Show Cohort Average" or "Show Competitor Average" in TWC Options, the average should appear as a LINE across the chart (not a separate bar).

## Steps
1. Reporting → Time Window Comparison.
2. Add MTV, Star Wars, HBO Max as brands.
3. Absolute date, Interval = **Aggregate**.
4. Metrics: Facebook New Fans, Twitter New Followers, Instagram Total Followers.
5. Options → **Show Cohort Average**.
6. Run Report.
7. Change Settings.
8. Options → **Show Competitor Average**.
9. Run Report.

## Assertions
- **A1 (after step 7):** Cohort Average displayed as a LINE across the chart, NOT as a separate bar.
- **A2 (after step 7):** Hovering over "Cohort Average" label shows a tooltip with the value.
- **A3 (after step 10):** Competitor Average displayed as a DOTTED LINE across the chart.
- **A4 (after step 10):** Hovering over "Competitor Average" label shows a tooltip with the value.
