# QA-113595 — Settings > Audit and Admin page changes

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-113595
- **Priority:** Minor
- **Description:** Ensure that Admin page changes are reflected on the Settings > Audit screen.

## Preconditions
- User logged in as Adam Orfei.
- Successful completion of QA-56761.
- Only execute on Dev.
- This test case should only be executed on Thursday.

## Steps
1. Hover over the key icon on the top right.
2. Click on 'Admin'.
3. Click on the Title input box in the Filters section.
4. Type the newly created brand name and click on it.
5. Edit the name in the Title box.
6. Click on 'Update Movie' and log out of the admin page.
7. Log in to app.lfmdev.in as 'Adam Orfei'.
8. Navigate to Settings > Audit page.

## Assertions
- A6 (step 6): Brand is updated.
- A8a (step 8): Actor column displays your name.
- A8b (step 8): Activity Type is displayed as 'Brand Edited'.
- A8c (step 8): Description displayed as 'Brand #{brand name} metadata was edited.'
