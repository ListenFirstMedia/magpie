# QA-134274 — Brand > Content - Verify pill add/remove, Clear All and Save/Load filter

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134274
- **Priority:** —
- **Description:** Ensures pill changes query correctly, Clear All resets all filters, and Save/Load fully restores Include/Exclude state, operators and pill colors.

## Preconditions
- User logged in as Adam Orfei
- Brand with multiple tags available (MTV)

## Steps
1. Navigate to Brand > Content (MTV, IG, default 7-day window)
2. Open Filter dropdown → Tag
3. Add Include tag → verify green pill renders
4. Remove the pill via the X / dismiss control on the chip → verify pill removed and filters JSON reflects removal
5. Re-add 2 Include tags + 1 Exclude tag → Apply
6. Click Clear All control → verify all pills + URL `filters` JSON cleared
7. Re-build a filter combination → Save (if a Save Filter UI exists; else verify URL persistence on reload)
8. Reload the page (F5) — verify pill state restored from URL
9. Verify pill colors: Include = green, Exclude = red

## Assertions
- A1: Pill add updates URL `filters` JSON
- A2: Pill remove (X click) clears that chip from URL
- A3: Clear All removes all pills and clears `filters` from URL
- A4: After F5 reload, URL `filters` JSON re-hydrates pill state (Include/Exclude + operator + tags)
- A5: Pill color: green for Include, red for Exclude
- A6: Brand-content-filter skill mechanics already verified on QA-134272/273; this case extends with the add/remove/Clear-All flow
