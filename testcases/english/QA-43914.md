## Preconditions
User has access to `radaac.lfmdev.in` and is logged in via Google SSO as the configured test user.

## Steps
1. Navigate to `https://radaac.lfmdev.in/`.
2. Find the report row labeled "Facebook User Accounts" (or similar wording).
3. Click the row → confirm a popup with the report's description text appears.
4. Choose file format `csv` from the dropdown.
5. Click Submit. Wait for the "File is Ready" page with a download link.
6. Click the download link. Wait for the file to save to `~/Downloads`.
7. Inspect the downloaded file: filename pattern, columns, row count, separator (defense-in-depth vs prior CSV→TSV regression).

## Assertions
A1. Report row "Facebook User Accounts" is present on Radaac and clickable.
A2. The popup shows a description of the report.
A3. File format dropdown lists `tsv`, `csv`, `xls`.
A4. Submitting with `csv` produces a "File is Ready" page with a `/cache/<file>.csv` link.
A5. Downloaded file has a sensible filename pattern (date prefix + report name + hash suffix + `.csv`).
A6. File is genuine comma-separated (not tab-separated regression — same defense-in-depth as QA-51425).
A7. Columns and content are consistent with a Facebook User Accounts report (e.g., user id / display name / token state / brand / etc.).
