## Preconditions
User logged in with permissions to edit brand basic info on Settings > Brands. Any active account.

## Steps
1. Navigate to Settings > Brands.
2. Pick a test brand (one that the test user is authorized to edit; prefer a low-stakes brand on the active account).
3. Open the Edit Brand modal/page.
4. Modify a basic info field (e.g., Brand Name suffix or a non-channel handle field) with a timestamped marker like `qa-48160-rerun-<YYYY-MM-DD-HHMM>`.
5. Save the changes. Confirm the value persists.
6. Re-open Edit Brand. Verify the change is visible.
7. **Cleanup (NON-OPTIONAL):** Revert the brand field to its original value. Save. Verify the original value is restored.
8. (Optional sub-flow) Add an invalid channel handle (e.g., bad-character IG username) to surface APPS-59449 — channel validation error does not appear until field loses focus.

## Assertions
A1. Settings > Brands list loads with the editable Brand row.
A2. The Edit modal/page opens and exposes Basic Info fields (Brand Name, possibly URL, description, etc.).
A3. A valid edit can be saved without errors. After save, the new value displays on the brand row and inside the modal on re-open.
A4. After cleanup revert, the original value is fully restored.
A5. (If sub-flow exercised) Invalid channel handle does not flag an error until the field loses focus — confirming APPS-59449's documented gap (do NOT file as new).
