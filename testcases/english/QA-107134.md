# QA-107134 — Settings > Audit - Deep Linking

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-107134
- **Priority:** Minor
- **Description:** Ensure the page loads correctly while pasting the URL in Audit tab (deep linking).

## Preconditions
- User logged in.

## Steps
1. Settings → Audit.
2. Copy the current full URL of the Audit page (with any applied filters/date range).
3. Open the URL in a new tab.
4. Verify the Audit page loads with the same filters/state as captured.
5. (Repeat) — replace the URL in the same tab and observe whether parameters persist.

## Assertions
- A1: Deep-link URL in fresh tab loads Audit page with same date range / filters.
- A2: All deep-link parameters (account, date range, filters) preserved.
- A3 (probe): APPS-54603 — when replacing URL in same tab, parameters except date range may not be applied.

## Probes (open bugs)
- APPS-54603 (Minor) — Global Deep Linking issue when replacing URL on current page; pasted URL not updated with selected parameters except date range.
