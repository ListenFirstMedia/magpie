## Preconditions
User logged in. A brand with Brand > Insights data is available (Hulu has authorized cross-channel data).

**IMPORTANT (known-quirk):** Brand Insights with Last 6/12 Months range freezes Chrome MCP renderer. Use Last 30 Days or shorter (and prefer Last 7 Days).

## Steps
1. Navigate to Brand > Insights for Hulu (or fall back to Adam Orfei → MTV per QA-10387 pattern).
2. Use a short date range — Last 7 or Last 30 Days.
3. Confirm the page loads.
4. Locate the Engagements tile (may live inside the consolidated Trends tile depending on build — per QA-10387 finding the modern Trends tile consolidates Impressions / Video Views / Engagement Rate).
5. Look for the tile-level Export / PNG affordance.
6. If present: click Export → PNG, wait for download, verify PNG on disk.
7. If absent: document spec drift (per QA-10387 batch-3 finding) — Brand Insights tile-level PNG export may be absent from current Trends-consolidated build.

## Assertions
A1. Brand > Insights loads (no Chrome MCP renderer freeze on Last 7 Days / Last 30 Days).
A2. Either: an Engagements tile (or Engagements-line inside Trends) exposes a tile-level Export menu, OR the absence is documented as spec drift (NOT a new bug).
A3. If PNG export reachable: file downloads to disk, filename pattern matches `{Brand}-Insights-Engagements-{ChartType}-{from}-{to}.png`.
A4. If PNG export reachable: PNG embeds chart title, chart data, axes, legend, date range.
A5. If PNG export absent on current build: mark BLOCKED with spec-drift finding, do NOT file as defect, cross-reference QA-10387 batch-3 outcome.
