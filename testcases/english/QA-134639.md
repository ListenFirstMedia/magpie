## Objective

Verify that on the Brand > Insights page, Export (CSV and Google Sheet) produces accurate, correctly-aggregated data for each Interval option (Daily, Weekly, Monthly, Quarterly), including the Brand Reputation Index tile which uses special aggregation. Also verify that exported values match the Time Window Comparison report for an equivalent date range and interval (TWC parity).

## Steps

1. Navigate to Brand > Insights for MTV with a short range (Last 30 Days max per known-quirk).
2. Select Daily interval; export a tile (e.g., Total Followers) as CSV; verify per-day aggregation.
3. Repeat for Weekly, Monthly, Quarterly intervals (use longer-supported ranges only if Chrome MCP renderer holds).
4. Identify Brand Reputation Index (BRI) tile (if available on current build); export and verify special-aggregation behavior.
5. Run an equivalent TWC report for the same brand + date range + interval; compare numerics.
