## Description
This test case ensures the Unauthorized brand check for Instagram channels, Reels dataset.

## Preconditions
User logged in as Adam Orfei.

## Steps
1. Click Brand in the top nav and select the Content tab.
2. Type and Select 'Star Wars' in the brand dropdown.
3. Click the Data Set drop-down and select "Reels" data set.
4. Select Instagram channel only.
5. Note the Mixed metrics: Engagements, Reactions, Comments values.
6. Open a New tab.
7. Navigate to Brand in the top nav and select the Content tab.
8. Switch the perspective to Public.
9. Select Instagram channel only.
10. Apply Filter: Publish Type as Reels.

## Assertions
- A1 (step 4): Ensure the Private Metrics show a lock symbol (Private Metrics: Shares, Reach, Plays, Initial Plays, Replays, Avg Time Watched (Minutes), Video Views Total Time (Minutes)).
- A2 (step 4): Ensure the Aggregate values display en-dash for Sum and Average for Shares, Plays, Initial Plays, Reel Plays, Video Views Total Time (Minutes).
- A3 (step 4): Ensure the Aggregate values display en-dash for Reach and N/A for Avg Time Watched (Minutes).
- A4 (step 4): Ensure the SUM values display en-dash for Reach and N/A for Avg Time Watched (Minutes) for Average.
- A5 (step 10): Ensure the value of the Mixed metric (from step 5, Authorized/mixed-auth tab) matches the Public value (from the Public-perspective tab, steps 6-10).

## Cleanup
None — read-only verification, no mutation. Close the extra tab opened in step 6 at the end of the run.
