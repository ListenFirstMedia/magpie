# QA-103248 — Brand Sets > Content - Daily Post Analysis Modal - Export - PNG & Google Sheets

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-103248
- **Priority:** Minor (P4)
- **Description:** Ensures the PNG & Google Sheets export functionality of the Daily Analysis Modal on the Brand Sets Content Page.

## Preconditions
- User should be logged in as Adam Orfei

## Steps
1. Click Brand Sets in the top nav and click Content in the dropdown
2. Click the Brand Set dropdown, Type and select 'LF // TV // Episodic' from the list
3. Click the 'Daily Analysis' button displayed below the first post
4. Click the data viz dropdown and select the 'Bar' option
5. Click the Export Dropdown in the top right of the modal
6. Select 'PNG' in the dropdown
7. Click the Export Dropdown and select 'Google Sheets'
8. Click the 'Close' button

## Assertions
- A1 (step 6): Ensure the filename is [Brand Name]-Daily Content Analysis-[Graph Type]-YYYY-MM-DD-YYYY-MM-DD.png (Ex. Jennifer Hudson Show-Daily Content Analysis-Bar-2025-01-24-2025-01-28.png) *(strikethrough on "Daily Content Analysis" in spec — may indicate updated format)*
- A2 (step 6): Ensure the ListenFirst Logo with the name displayed in the top left corner above the Brand name
- A3 (step 6): Ensure the 'Daily Content Analysis' text with date range displays below the graph
- A4 (step 6): Ensure the PNG matches the page
- A5 (step 7): Ensure the filename is [Brand Name]-[Publish Time PST]-[Publish Channel]-Daily Content Analysis-YYYY-MM-DD-YYYY-MM-DD (Ex. Jennifer Hudson Show-Jan 26 2025-09-46 AM PST-Instagram-Daily Content Analysis-2025-01-26-2025-01-28) *(strikethrough on "[MON DD YYYY]" — interpret as updated format)*
- A6 (step 7): Ensure the date format should be YYYY-MM-DD(2025-01-26)
- A7 (step 7): Ensure the Google Sheets data matches with the page data
- A8 (step 8): The window closes
