# QA-51425 — Duplicate Brands and Social Pages Report on Radaac

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-51425
- **Priority:** Blocker (P1)
- **Description:** Ensure the no-duplicate functionality on Radaac report.

## Preconditions
- User logged into Dev Radaac (https://radaac.lfmdev.in/)

## Steps
1. In Radaac tab, search for report 'Duplicate Brands and Social Pages'
2. Click Duplicate Brands and Social Pages
3. Click File Format dropdown in Options Field
4. Click CSV
5. Click Submit button

## Assertions
- A1 (step 2): Popup opens with message "The report will pull a list of all brands in the platform that have one of the same social pages associated to multiple brands (Facebook, Twitter, Instagram). This pull should exclude brands with the same name (public and extended)"
- A2 (step 5): CSV file downloaded after a few seconds
- A3 (step 5): Filename `YYYYMMDDDuplicateBrandSocialPages_caacfb.csv`
- A4 (step 5): Columns Brand ID, Brand Name, Title Category, Channel, Url, Perspective
- A5 (step 5): Duplicate column should NOT display
