## Description
This test case ensures that reel posts are displayed when the reel publish type filter is applied for the Facebook channel for the latest dates.

## Preconditions
The user logged in as Hulu.

## Steps
1. Click Brand in the top nav and select the Content tab.
2. Type and Select 'Hulu' in the brand dropdown.
3. Select a Facebook channel and select Last 90 days.
4. Click filter dropdown.
5. Select Filter as Content type: Video and Publish type: Reel.
6. Click Apply filter.
7. Click Detail view.
8. Click Exclude in the Publish type: Reel filter.
9. Click Apply filter.

## Assertions
- A1 (step 6a): Ensure the correct post count has been updated.
- A2 (step 6b): Ensure only Facebook reel posts are displayed.
- A3 (step 7): Ensure only Reel posts are displayed in the detail view.
- A4 (step 9): Ensure that Reel posts are not displayed on the page (after excluding Publish type: Reel).

## Cleanup
None — read-only verification, no mutation.
