## Description
This test case verifies that the Post aggregate values match the All Insights tiles aggregate value for Facebook Reel.

## Preconditions
User logged in as Hulu.

## Steps
1. Click Brand in the top nav and select the Content tab.
2. Type and Select 'Hulu' in the brand dropdown.
3. Select Facebook channel only and Select date range as (04-09-2025 to 04-15-2025).
4. Click the Data Set drop-down and Select the 'Public' option from the drop-down.
5. Click the filter dropdown and Apply the filter as Publish type: 'Reel'.
6. Note down the Facebook reel post count and aggregate sum values for Engagements, Reactions, Comments, Shares.
7. Exclude the applied filter.
8. Note down the Facebook reel post count and aggregate sum values for Engagements, Reactions, Comments, Shares.
9. Sum the noted values for the included and excluded filter metrics for Engagements (same for Reactions, Comments, Shares, and Post Count).
10. Remove the applied filter.
11. Review all insights tiles aggregate values for (Engagements, Reactions, Comments, Shares, Engagement Rate, and Impressions).

## Assertions
- A1 (step 5): Ensure the Engagement Rate content insights tile shows the Engagement Rate value for Facebook Reels.
- A2 (step 10): Ensure the Sum value of the posts (Reel-included + Reel-excluded) is equal to the New Post tile count.
- A3 (step 11): Ensure the Sum of each metric aggregate (Reel-included + Reel-excluded) is equal to the insights tile aggregate value (Engagements, Reactions, Comments, and Shares).
- A4 (step 11): Ensure that the division of Engagements/Impressions*100 equals the Engagement Rate. Formula: Engagement Rate = (Engagements/Impressions)*100.

## Cleanup
None — read-only verification, no mutation.
