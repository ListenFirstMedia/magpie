# QA-109749 — Brand Audience > Threads - Hovering Functionality

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-109749
- **Priority:** Minor
- **Ingested:** 2026-07-13 from Jira (Xray custom fields)

## Preconditions
User should be logged in as Adam Orfei

## Steps
1. Click Brand in the top nav and select 'Audience' tab
2. Click the Brand dropdown, type and select 'NFL on CBS' brand
3. Select 'Threads' Channel in the channel selector, set the date range as April 1, 2025, to April 5, 2025
4. Hover over 'Followers By Country' tile
5. Hover over 'Followers By City' tile
6. Hover over 'Followers: Gender Breakdown' donut chart

## Assertions
4(a). Ensure hovering over 'Followers By Country' tile displays the percentage value.
4(b). Ensure tooltip displays in the following format:
- Legend : Country Name
- Followers (N%)
5(a). Ensure hovering over Cities [Red dots] displays the percentage value.
5(b). Ensure tooltip displays in the following format:
- Legend : City Name, Country
- Followers (N%)
6(a). Ensure 'Men', 'Women' and 'Unknown' are displaying in the legend label.
6(b). Ensure tooltip displays in the following format:
- Men: N%
- Women: N%
- Unknown: N%
