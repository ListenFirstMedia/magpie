## Preconditions
- User logged in as Adam Orfei

## Steps
1. Settings → Custom Metrics
2. Click Create a Custom Metric
3. Name: `Automation - Mult Div Metric`
4. Description: `Mult and div operator coverage`
5. Click Formula input
6. Metrics → Facebook → Post Comments
7. Operators → `×` (multiply)
8. Metrics → Facebook → Post Likes
9. Operators → `÷` (divide)
10. Metrics → ListenFirst → Shares
11. Wait for Save enabled
12. Click Save
13. Success popup → OK

## Assertions
- 2: Save disabled on open
- 7-A: Operators dropdown lists exactly `+`, `−`, `×`, `÷` (4 options)
- 7-B: After selecting `×`, formula row contains operator chip `×`
- 9: Formula row contains operator chip `÷`
- 10: Formula row 5 chips: [Post Comments, ×, Post Likes, ÷, Shares]
- 11: Save enabled
- 13-A: Success popup text = "Custom metric successfully created!"
- 13-B: Listing table contains row `Automation - Mult Div Metric`
