## Preconditions
- User logged in as External account (Analyst No Spend role)
  Username: testing@drylogics.com
- User logged into Hulu Account

## Steps
1. Click Brand in top nav and select Paid in the dropdown
2. Click the Brand dropdown, Type and select Hulu brand
3. Select 'Twitter' channel
4. Change date range as Sep 10 2022 to Sep 18 2022
5. Click Data Set dropdown and select 'Cost' data set
6. Click Export dropdown and select 'Only Current Data Set'
7. Click the 'Ok' button in the pop-up
8. Hover the notification icon
9. Click 'Download File' in the notification

## Assertions
- A1 (5): 'Go to Authorize' displays in the Spend tile
- A2 (5): Spend, CPC, CPM and CPE metrics should display lock symbol in the post table
- A3 (5): The Aggregate table displays endash for the Spend metric
- A4 (9): Spend, CPC, CPM and CPE metrics column should be empty in the CSV file
