## Description
This test case ensures that for Both Public and Authorised perspective Reel data check for Facebook channel.

## Preconditions
User logged in as Fx Networks.

## Steps
1. Click Brand in the top nav and select the Content tab.
2. Type and Select 'FX' in the brand dropdown.
3. Set the date range from August 01, 2025 to August 10, 2025.
4. Select 'Facebook' channel only.
5. Click the filter dropdown and Apply the filter as Publish type: 'Reel'.
6. Change the perspective to 'Public'.

## Assertions
- A1 (step 5, Authorized perspective — default before toggling): Ensure all metrics show data and no metric displays en-dash (—) for Facebook Reels posts under Authorized perspective.
- A2 (step 6, after toggling to Public): Ensure all metrics show en dash (—) for Facebook Reels posts under Public perspective.

## Cleanup
None — read-only verification, no mutation.
