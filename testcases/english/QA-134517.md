## Objective

Verify that on the Reporting > Data Studio page (`app-reporting.lfmdev.in/#/data_studio`), users can simultaneously Include and Exclude tags in the same filter set, mirroring the behavior delivered for Brand > Content.

## Steps

1. Navigate to Reporting > Data Studio builder.
2. Add a brand (MTV) and select a date range.
3. Locate the Tag Filter affordance.
4. Open the Tag Filter sub-popup; verify Include/Exclude radios + Or/And operator + checkbox list.
5. Add an Include tag with Or.
6. Switch to Exclude — verify Include tags greyed.
7. Add an Exclude tag.
8. Apply Filter; capture URL params.
9. Run the report; verify data reflects layered filter.

| ID | Step | Expected | Actual | Status |
|----|------|----------|--------|--------|

| A3 | Step 8 | URL or filter state encodes Include + Exclude tag predicates | | |

## Notes

- The V2 sweep flagged that Reporting > Content Performance Tag Filter lacks Include/Exclude (only Or/And + checkboxes). Determine if Data Studio has the same divergence or supports the full Include/Exclude pattern. If absent, document as known-quirks parity gap.
