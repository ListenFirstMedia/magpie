## Description
On Brand > Content for Facebook, hovering the Type column of a FB post row opens an embedded FB tooltip with thumbnail + caption + close X. Click opens FB post URL in new tab.

## Preconditions
User logged in as Adam Orfei. FB-enabled brand. Brand > Content Table layout.

## Steps
1. Brand → Content, brand = MTV (or similar FB-eligible), channel = Facebook only, Default In-Window, recent date window.
2. Table layout selected.
3. Posts(N>0) for FB.
4. Hover the Type column of a FB row.
5. Read the embedded tooltip content (post image / thumbnail + caption + close X).
6. Click X to close.
7. Click the Type link of another FB row — verify a new tab opens to `facebook.com/...` URL.

## Assertions
- A1 (step 3): Posts(N>0) for FB.
- A2 (step 5): Tooltip renders thumbnail + caption byline.
- A3 (step 5): Only one tooltip open at a time.
- A4 (step 6): X closes tooltip.
- A5 (step 7): Click opens new tab to a `facebook.com` URL matching the post.
