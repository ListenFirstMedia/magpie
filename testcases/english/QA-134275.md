# QA-134275 — Brand > Content - Verify Include-only filter returns correct results for OR and AND operators

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134275
- **Priority:** —
- **Description:** Ensures OR returns posts matching any included tag and AND returns posts matching all included tags. AND must be explicitly selected. Green pills shown for Include tags.

## Preconditions
- User logged in as Adam Orfei
- Brand with at least 2 tags shared across some posts (MTV)

## Steps
1. Navigate to Brand > Content (MTV, IG)
2. Open Filter → Tag — Include radio active by default
3. Add 2+ Include tags
4. Apply with OR (default) — record Posts(N) for OR
5. Re-open pill → switch to AND → Apply — record Posts(N) for AND
6. Verify pill colors green
7. Verify URL `filters` JSON encodes `operator:or` then `operator:and` with `not:false`

## Assertions
- A1: OR Include count ≥ AND Include count (OR is a superset)
- A2: AND requires explicit click; not selected by default after enablement
- A3: Pill chips are green
- A4: URL `filters` JSON encodes `operator` correctly per state
- A5: Posts table updates after each Apply (or known table-failed-to-load quirk fires when 2-tag intersect is empty — extension of QA-134277 quirk)
