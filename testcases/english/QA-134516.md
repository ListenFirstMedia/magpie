# QA-134516 — Reporting > Content Performance - Verify layered tag filtering (Include + Exclude)

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134516
- **Priority:** Critical (P2)
- **Description:** Verify Reporting > Content Performance supports simultaneous Include + Exclude tag filtering (mirrors Brand > Content per QA-134443).

## Preconditions
- User logged in with access to HBO Max account
- Tags applied to posts to use in filters

## Steps
1. Reporting > Content Performance
2. Account HBO Max; brand from LF // TV // EPISODIC brandset
3. Date range Last 7 Days
4. Open Tag Filter panel
5. Add tag to Include
6. Attempt to add the same tag to Exclude
7. Add another tag to Exclude
8. Toggle Include/Exclude logic OR/AND
9. Click Go
10. Change Settings → Clear All on filter panel
11. Re-add same tags to Include/Exclude, remove only Exclude
12. Save layered filter, reload, reopen with saved report
13. Generate report → export CSV (and GS where applicable)

## Assertions
- A1 (step 4): Tag Filter panel opens with Include + Exclude sections visible/empty
- A2 (step 5): Tag added to Include; report preview reflects only posts matching that tag
- A3 (step 6): Same tag greyed out/non-selectable in Exclude
- A4 (step 7): Tag added to Exclude; data reflects Include AND NOT Exclude
- A5 (step 8): OR/AND toggle updates report data (OR = any Include; AND = all Include)
- A6 (step 9): Report shows only posts matching filters
- A7 (step 10): Clear All empties both Include + Exclude sections
- A8 (step 11): Removing only Exclude returns Include-only result; Include remains
- A9 (step 12): Saved layered filter persists after reload
- A10 (step 13): Exported CPR (CSV/GS) contains only rows matching layered filter
