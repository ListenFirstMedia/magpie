## Preconditions
User logged in. A brand (Hulu preferred per sibling QA-575) with multi-channel Video Views data is available.

## Steps
1. Navigate to Brand > Content for Hulu (or other brand on the active account).
2. Confirm default channel selection (defaults to all available channels).
3. Click the Data Set dropdown and select `Video Views`.
4. Verify Posts (N) tile populates with non-zero posts and the columns reflect Video Views metric set.
5. Click Export → CSV (queued export via CDN — read filename from Recent Activity bell).
6. Wait for the CSV to be ready, fetch via the canonical CDN URL (`fetch(url, {credentials:'include'})`).
7. Save file to disk and inspect: row 1 header, row 2 metric label row, data rows.

## Assertions
A1. The Data Set dropdown contains `Video Views` (and a generic `Public` / `Organic Performance` default).
A2. After selecting Video Views, the Posts(N) tile loads (no skeleton-hang) within reasonable time.
A3. Export CSV is enabled; queued export completes; Recent Activity bell shows entry.
A4. Filename pattern matches `{Brand}-Brand Content-{from}-{to}-{...}.csv` (brand + tab + date range + suffix).
A5. CSV contains Video Views metric columns (e.g., Video Views, Avg Watch Time, etc., depending on current Video Views metric set).
A6. Row 1 of CSV labels the data set as the active one (per `export-csv` v2 pattern).
