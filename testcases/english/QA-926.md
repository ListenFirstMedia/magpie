## Description
On Brand > Content for YouTube, hovering the Type column of a YouTube post row opens an embedded YouTube tooltip with thumbnail + caption metadata + close X. Clicking the type link opens the YouTube video page in a new tab.

## Preconditions
User logged in as Adam Orfei. YouTube-eligible brand. Brand > Content Table layout.

## Steps
1. Brand → Content, brand = MTV (or similar YT-enabled), channel = YouTube only, Default In-Window, recent date window.
2. Table layout selected (use `[title="Table View"]` JS click).
3. Verify Posts(N>0) with YT rows.
4. Hover the Type column link/icon of a YT row.
5. Read the embedded tooltip content (image / video thumbnail + caption text + close X).
6. Click X on the tooltip — verify it closes.
7. Click the Type link of another YT row — verify a new browser tab opens to YouTube watch URL for that video.

## Assertions
- A1 (step 3): Posts(N>0) for YT in the chosen window.
- A2 (step 5): Embedded tooltip renders thumbnail (visible image element) + caption byline (text "Published By <brand>" or equivalent).
- A3 (step 5): Only one tooltip is open at a time.
- A4 (step 6): Close X removes the tooltip.
- A5 (step 7): Clicking Type link opens a new tab to `youtube.com/watch?v=` URL for the post's video.
- A6 (step 5): Position of tooltip is anchored to the hovered row (does not render in viewport-corner).
