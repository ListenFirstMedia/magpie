## Preconditions
User logged in as Sephora.

## Steps
1. Brand → Content.
2. Type & select brand 'Sephora'.
3. Select only Pinterest channel.
4. Date range = Jun 21, 2023 – Jun 22, 2023.
5. Select Table view in View mode.
6. Hover over options in Type column.

## Assertions
- A1 (6a): Post tooltip displays on hover.
- A2 (6b): Only one tooltip visible at a time.
- A3 (6c): Tooltip closes on X click OR clicking elsewhere.
- A4 (6d): Hovering other Type links doesn't open additional tooltips.
- A5 (6e): Clicking post type opens correct channel post in new tab matching tooltip.
- A6 (6f): Post image + Post text match the tooltip content.

Note: Check some random posts that no external pin appears → if found, raise a bug.
