## Preconditions

## Steps
1. Click Search icon in nav.
2. Type "Lowell Milken Center for Music of American Jewish Experience".
3. Hover over result.
4. Select brand.
5. Type same string in brand search container.
6. Hover.
7. Brand Sets → Content. Type "UCLA School of the Arts and Architecture Roll-up" in brand set container.
8. Hover.
9. Reporting → Time Window Comparison. Type Lowell Milken… in brand container.
10. Hover ellipsis.

- A1 (3a): Brand displayed in two rows, both highlighted.
- A2 (3b): Full brand name in tooltip on hover.
- A3 (4): Page navigates to Brand → Insights.
- A4 (6a/b): Same two-row + tooltip behavior in brand search container.
- A5 (9a/b): Same in brand set container.
- A6 (12a-c): Same two-row + ellipsis + tooltip in TWC brand container.
