# QA-106218 — Settings > Custom Data Sets - Create a New Custom Data Set functionality

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-106218
- **Priority:** Blocker (P1)
- **Description:** Ensures the Create a new custom data sets functionality.

## Preconditions
- User logged in as Adam Orfei

## Steps
1. Hover over 'Settings' in the top nav
2. Click 'Custom Data Sets' in the dropdown
3. Click 'Create a Custom Data Set' button
4. Review the page
5. Click 'Data Set Name' box and type a unique name
6. In the Metrics table, click on the Public node and select metrics: Engagements, Reactions, Response Rate
7. Click the respective node and select:
   - Engagements Breakdown → Comments, Shares
   - Impressions → Engagement Rate, Impressions
8. Click 'Create' button
9. Review newly created Custom Data Set row

## Assertions
- A1 (step 4): Breadcrumb updates to "Account: Adam Orfei | Settings > Custom Data Sets > New Custom Data Set"
- A2 (step 4): Header "Create Custom Data Set" displays below breadcrumb
- A3 (step 4): "Data Last Updated" timestamp in format "MM-DD-YYYY | HH:MM AM/PM PT", non-clickable
- A4 (step 4): "Data Set Name" box with placeholder "Enter your data set's name" displays under header
- A5 (step 4): Metrics order: Public, Engagements Breakdown, Impressions, Video Views, Clicks, Reels, Facebook, Twitter, Instagram, YouTube, Threads, Pinterest
- A6 (step 6): Selected metrics are checked and appear in 'Selected Metrics' table
- A7 (step 7): Metrics "Comments, Shares, Engagement Rate, Impressions" have lock icon after metric name
- A8 (step 7): Metrics "Engagements, Reactions, Response Rate" don't have any icons after metric name
- A9 (step 7a): Selected Metrics table header updates to "Selected Metrics (7)"
- A10 (step 7b): "Data Last Updated" timestamp remains visible while selecting metrics
- A11 (step 8): Page navigates to Custom Data Set listing table
- A12 (step 8a): Newly created custom data set displays in Data Set listing table
- A13 (step 9): Metrics displaying in the added order
- A14 (step 9a): "Data Last Updated" timestamp remains visible, non-clickable, consistent format
