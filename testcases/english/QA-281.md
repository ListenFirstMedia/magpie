# QA-281 — TWC report for Relative dates with long intervals

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-281
- **Priority:** Trivial (P5)
- **Description:** User should see metrics in TWC report and TSV exports for longer intervals.

## Preconditions
- User logged in as Disney Ad Sales

## Steps
1. Reporting → Time Window Comparison
2. Select Relative dates
3. Weeks interval
4. Start 15 weeks out, end 1 week
5. Add 3 brands: Disney Channel, Disney Junior, Wells Fargo
6. Key date Feb 1, 2025
7. Metric: New Followers
8. Story options: Show Change, Show Share, Show Metrics Tables
9. Generate report
10. Observe report
11. Export → CSV

## Assertions
- A1 (step 12): Exports match TWC report
