## Preconditions
User should be logged in as Hulu.

## Description
This test case ensures the user is able to export a report in the form of a Google Sheet.

## Steps
1. Click **Reporting** in the top nav.
2. Select **Time Window Comparison**.
3. Select **Absolute** dates.
4. In the **Add brand by name** field, enter `Hulu (Public Data)`.
5. Add some data points (e.g., check **Facebook New Fans**).
6. Run Report.
7. Export to Google Sheets by clicking **Google Sheets** in the Export dropdown.
8. Click **CSV** in the Export dropdown.

## Expected
- A Google Sheets export is generated.
- A CSV export is generated.
- The exports are consistent with each other.

## Assertions
- **A1 (step 7) — Filename pattern:** Exported file name matches `Brand - Time Window Comparison - <begin_date> - <end_date>` exactly (where `<begin_date>` and `<end_date>` are the absolute dates selected).
  - type: regex / text pattern
  - source: filename of downloaded Google Sheets and CSV
- **A2 (step 7) — Perspective column value:** The `Perspective` column in the export displays `Public` (since the brand is `Hulu (Public Data)`).
  - type: text_equals (after trim)
  - source: column in Google Sheets export (and CSV)
- **A3 (step 8) — Cross-export parity:** The Google Sheets export and the CSV export contain the same data, cell-by-cell, after format normalization (numbers, dates, percent representations).
  - type: table (cross-source)
  - source: Google Sheets vs CSV

## Notes
- "Hulu (Public Data)" implies the public-data perspective on the Hulu brand — not the licensed/owned data. Perspective column should reflect this.
- Date range matters for the filename assertion — record the exact begin/end dates used so we can verify the filename precisely.
- Google Sheets export likely requires the user to be authenticated to a Google account; capture any auth prompts.
- Capture console + network throughout, especially the export requests (likely `/api/export/google-sheets` and `/api/export/csv` or similar).
