# QA-89390 — Dashboards - Brand Content Insights - Functionality to save filtered tiles to the dashboard

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-89390
- **Priority:** Critical
- **Ingested:** 2026-07-13 from Jira (Xray custom fields)

## Preconditions
User should be logged in as Adam Orfei

## Steps
1. Hover over the Brand dropdown and Click Content
2. Click the Brand dropdown and Select 'MTV'
3. Click the Insights dropdown and Select All Insights
4. Click the filter dropdown and apply the filter as 'Content-Type: Video' and for 'Text Search: Use sample text from the first post's caption'
5. In the New Posts tile, Click Save to Dashboard dropdown and Click Create Dashboard
6. Type 'Brand Content insights Dashboard' and Click ok Button
7. In the Performance by Type tile, Click Save to Dashboard dropdown
8. Click the checkbox in the already saved name 'Brand Content Dashboard'
9. Click the Dashboards button in the top nav
10. Review the saved tiles in the created dashboard
11. Hover the cursor over the filter

## Assertions
10(a). Ensure the applied filter appears on both brand content insights tiles
10(b). Ensure the filter cannot be edited
11. Ensure that the tooltip appears when the cursor is placed over the filter

Per Jira: In automation, fixed start date and end date are provided to reduce the complexity of data.
