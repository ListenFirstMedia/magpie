# QA-98368 — Brand Content - Threads - Post Type Hovering functionality

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-98368
- **Priority:** Minor (P4)
- **Description:** Ensures the hovering post type functionality for the Threads channel on the Brand Content tab.

## Preconditions
- User should be logged in as HBO Max acct

## Steps
1. Hover Brand in top nav and click Content
2. Click Brand search drop down and type and select 'HBO Max' brand
3. Select only the 'Threads' channel and click Apply
4. Select table view in the view mode
5. Hover over post type in the post column
6. Click on the post type

## Assertions
- A1: Ensure post tooltip displays when hovering the Post type link in the Type column.
- A2: Ensure user can view only one tooltip.
- A3: Ensure the tooltip closes when clicking 'X' in the upper right or somewhere else on the page
- A4: Ensure hovering other post type link will not open additional tooltips
- A5: Ensure when clicking the post type, it opens the correct channel post in a new tab and it matches to the Post tooltip
