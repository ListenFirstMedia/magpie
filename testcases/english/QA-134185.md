# QA-134185 — Settings > Custom Metric Creation - Info View

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134185
- **Priority:** (not retrieved in full)
- **Description:** Verify In Settings > Custom Metric Creation, Info View displays a persistent tooltip that dynamically updates based on hovered elements (Name, Description, Formula, Metric Definition Link) on the Create screen.

## Steps
1. Top Navigation → Settings
2. Custom Metrics
3. Click Create Custom Metric
4. Hover Name field WITHOUT Info mode
5. Click Info button
6. Observe tooltip without hovering anything
7. Inspect Create Custom Metric page elements
8. Hover Name field
9. Inspect Name field element
10. Hover Description field
11. Inspect Description field element
12. Hover Formula field
13. Inspect Formula field element
14. Click Info button (dismiss)
15. Hover Name, Description, Formula, Metric Definition Link

## Assertions
- Info mode initially shows generic tooltip
- Hovering Name / Description / Formula / Metric Definition Link in Info mode updates tooltip header + description
- Without Info mode, no persistent tooltip
- Clicking Info button toggles Info mode on/off
