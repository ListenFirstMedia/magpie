## Preconditions
User logged in as Michael Kors

## Steps
1. Hover over the Brand From top Nav and Select Content
2. Select 'SS22 New York Fashion Week Roll-Up' brand
3. Select 'Facebook' channel only and Click Table view
4. Change the date range from October 18, 2024, to October 18, 2024
5. Click 'Filter' dropdown and select 'Brand' filter
6. Type and select 'Tory Burch' Or 'Michael Kors' brand in the sub category filter search dropdown
7. Click Apply Filter
8. Click Table Data Set dropdown and select Impressions data set
9. Click the Export dropdown
10. Click the OK button in the export popup
11. Click the OK button in the Select Data Sets Export Request popup.
12. Open the corresponding Email and Download the attached CSV export in the mail

## Assertions
7. Ensure the 'Brand' column displays only 'Tory Burch' and 'Michael Kors' brand
7. Ensure the 'Michael Kors' post displaying data
7. Ensure the 'Tory Burch' Reel posts are displaying endash ('–')
8. Ensure posts by 'Tory Burch' display locks for private data points
8. Ensure 'Michael Kors' posts displaying data for all metrics
12. Ensure export displays blank cells for lock data points
12. Ensure only the filtered brand name is displayed in the 'Brand' column in the CSV file
12. Ensure that Facebook Reel posts are included in the export.
