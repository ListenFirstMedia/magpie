# QA-949 — Brand > Stories - Hovering Functionality

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-949
- **Priority:** Minor (P4)
- **Description:** Ensure the hover function of the Instagram summary and Story tab as desired.

## Preconditions
- User logged in as Michael Kors

## Steps
1. Click Brands and select Stories
2. Click the brand dropdown and type/select 'Michael Kors'
3. Hover over the graph bar
4. Click the graph type dropdown in the Impressions tile
5. Select 'Pie chart'
6. Hover the chart
7. Click the Export button in toolbar and select "Only Current Dataset" under CSV
8. Click post Type on all view

## Assertions
- A1 (step 3): Engagements, Impressions, Taps Back, and Exits big-number graph are hoverable
- A2 (step 3): Tooltip displays as 'DOM DD, YYYY' on next line with icon-Channel: N (e.g. Nov. 15, 2021 / icon-Instagram: 109,492)
- A3 (step 6): Tooltip displays as (icon-Instagram: Value)
- A4 (step 7): Spinner displays on Export button until file download
- A5 (step 8): Opens a new tab with the correct post
