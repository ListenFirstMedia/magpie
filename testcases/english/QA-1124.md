## Preconditions
User logged in as Hulu.

## Steps
1. Hover Brand → click Insights.
2. Brand dropdown → type "Hulu".
3. Select brand from list.
4. Set date range = 30 days.
5. Right-hand corner → click View Toggle to Public Data → review all bar graphs.
6. Hover stacked bar chart "Follower Growth".
7. Hover stacked bar chart "New posts".
8. Hover stacked bar chart "Engagements".
9. Hover stacked bar chart "Response Rate".
10. Hover stacked bar chart "Fan Growth Rate".
11. Hover area chart "Views".
12. Hover pie chart "Total Followers".
13. Data Visualization dropdown → select "Channel View: Aggregate".
14. Hover area chart "Public Video Views".

## Assertions
- A1 (5a): In every graph, tooltip data displays only for channels available in legend.
- A2 (5b): "Compared to" tweak available in all bar charts.
- A3 (6a): Chart is hoverable.
- A4 (6b): Tooltip format = `Mon. DD, YYYY` + `Channel names: Values`. Hovered channel highlighted.
- A5 (7): Hovered channel highlighted in tooltip.
- A6 (8): Hovered channel highlighted in tooltip.
- A7 (9): Tooltip format = `Mon. DD, YYYY` + `Chart Name: Values`.
- A8 (10): Tooltip format = `Mon. DD, YYYY` + `Chart Name: Values`.
- A9 (11): Tooltip format = `Mon. DD, YYYY` + `Channel icon Twitter: Values`.
- A10 (12a): Tooltip outlined as `icon Facebook: #N`.
- A11 (12b): Area chart updated to Aggregate View.
- A12 (13): Tooltips in correct format `Mon. DD, YYYY` + chart-name-prefixed value lines.
- A13 (14): Tooltip format = `Mon. DD, YYYY` + `Public Video Views: values`.
