## Preconditions
User logged in as Adam Orfei.

## Steps
1. Click Settings (top nav) → Users.
2. Click 'Add a New User'.
3. Select Account = Drylogics in dropdown (Account Info).
4. Enter first name, last name, and User mail ID **in incorrect format** → click Add User (expect error).
5. Enter User mail id in correct format.
6. Enter unique Phone no., Job Title (e.g., "Drylogics Contract") in Customer Info section.
7. Click Add User → page redirects to Settings Users → filter by new user email.
8. Navigate to Admin (key icon top nav) → Accounts → Users.
9. Back to Settings Users → Click Ellipsis in Actions column of new user.
10. Click Deactivate → OK.
11. Log into Dev Mixpanel → Users section.
12. Search for the deactivated user name.
13. Click into the user profile.

## Assertions
- A1 (2a): Page redirects to Add New User.
- A2 (2b): "Analyst" is default selection in Role dropdown.
- A3 (3): Role dropdown contains 'Admin', 'Analyst', 'Analyst (No Spend)', 'LF Employee'.
- A4 (4a): "Add User" button is enabled when text entered in email field.
- A5 (4b): Email field highlighted with Red icon + error "Received invalid email: 'email.com'".
- A6 (7): New user displayed in Users tab + success message "You've successfully added user@email.com!".
- A7 (8): New user displays in Users page in classic admin.
- A8 (10): Success message "You've successfully deactivated added user@email.com!".
- A9 (13a): "User Deactivated" displays below Activity Feed in Mixpanel.
- A10 (13b): Duplicate users not created in Mixpanel.

## Cleanup
The Deactivate step in #10 is the cleanup (test creates then deactivates same user).
