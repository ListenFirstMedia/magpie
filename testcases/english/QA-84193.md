## Steps (parity protocol — analogous to QA-90213)

2. Choose a fixed Absolute date window (e.g., May 27 – Jun 02 2026).
3. On Data Studio Post Level → Aggregate → add the brand → metric `Engagements` (or per-channel: Facebook Engagements, Twitter Post Likes+Replies+Retweets, IG Engagements, TikTok Engagements) → Run.
4. On Brand > Content → same brand → same date window → Public perspective → Sum column for Engagements.
5. Compare numeric Sum/Aggregate across DS and Brand > Content for each channel.
6. Record per-channel % delta; treat sub-1.5% drift as parity (per known-quirk).
