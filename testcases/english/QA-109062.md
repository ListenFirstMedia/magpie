# QA-109062 — Settings > Custom Data Sets support on Brand > Content - Export

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-109062
- **Priority:** Blocker (P1)
- **Description:** Ensures export functionality of newly created Custom Data Set in Brand Content page.

## Preconditions
- User logged in as Adam Orfei
- Successfully completed QA-106218

## Steps
1. Hover Brand → Content
2. Click brand selector, type and select 'MTV'
3. Click 'Data Set' dropdown and scroll down
4. Click on the data set created in Custom Data Sets page
5. Click 'Export' dropdown
6. Uncheck the data set
7. Select the data set we created and click 'Ok' in the export popup

## Assertions
- A1 (step 4): Selected data set updates in the data set dropdown
- A2 (step 4): Following metrics displayed in Aggregate table and posts: Engagements, Reactions, Response Rate, Organic Comments, Paid Comments, Organic Shares, Paid Shares, Engagement Rate, Impressions, Organic Impressions, Paid Impressions
- A3 (step 5): "Custom Data Sets Test" data set already selected and LF data sets in disabled state
- A4 (step 6): All data sets enabled except those related to Pinterest
- A5 (step 7): File name pattern "Brand-Tab-Start Date-End Date-posts.csv"
- A6 (step 7): No LF data sets should display
- A7 (step 7): CSV data matches Page data
