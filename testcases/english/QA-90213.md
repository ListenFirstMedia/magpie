- Brand: MTV (exact-match from Results, brand_id=4018).
- Public Data perspective on both pages.

## Steps
1. Reporting → Data Studio.
2. Post Level tab; Interval = Aggregate.
3. Add Brand MTV.
4. Select metrics: Twitter Post Likes + Twitter Post Replies.
5. Click Go; capture Sum.
6. Open a new tab: Brand → Content.
7. Search and select MTV from Results.
8. Select only Twitter channel.
9. Same Public perspective, same date range as DS Step 5.
10. Capture Reactions Sum + Comments Sum in Brand>Content Table view.

## Assertions
- A1: Data Studio "Twitter Post Likes" Sum == Brand>Content "Reactions" Sum.
- A2: Data Studio "Twitter Post Replies" Sum == Brand>Content "Comments" Sum.
