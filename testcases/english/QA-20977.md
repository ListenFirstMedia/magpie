## Description
This test case verifies tag functionality across views on Brand > Paid for TikTok, including Select All checkbox behavior.

## Preconditions
User logged in as Adam Orfei. TikTok-eligible brand under Brand > Paid.

## Steps
1. Brand → Paid, TikTok channel only.
2. Tag a post, verify tag count updates.
3. Switch between Table/Grid/Detail views, verify tag persists.
4. Open Filter → Tag, check Select All default state and behavior.

## Assertions
- A1: Tag button visible and functional on TikTok Paid posts.
- A2: Tag persists across view switches.
- A3: Select All checkbox behaves correctly in Tag filter.
