## Preconditions
User logged in as HBO Max.

## Steps
1. Click Settings (top right) → Data Collection.
2. Search for 'HBO Max'.
3. On HBO Max row, hover over Red exclamation point.
4. Click Learn More link.
5. Click on the brand.
6. In Channels, hover over Red exclamation for Facebook.
7. Click on Facebook channel.
8. Hover over Red exclamation for the Facebook page.

## Assertions
- A1 (3a): Popup opens with header "Not-Collecting (N)".
- A2 (3b): Learn More link visible top-right with icon.
- A3 (3c): Two Reauthorize buttons in popup.
- A4 (3d): Channel description includes "(Public)" e.g. "Twitter Ads (Public)".
- A5 (4): Learn More opens help-desk Data Collection Info in new tab.
- A6 (6a): Popup shows non-collecting items; scrollable.
- A7 (6b): Learn More link top-right with icon.
- A8 (6c): One Reauthorize button.
- A9 (7): Channels section shows currently-collecting channels.
- A10 (8a): Page-level popup shows Data Begins / Last Collection / Posts Tracked, scrollable.
- A11 (8b): All collected pages shown in Pages section.
- A12 (8c): Per-page popup shows individual page's Data Begins / Last Collection / Posts Tracked.
