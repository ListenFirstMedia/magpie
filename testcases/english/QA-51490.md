# QA-51490 — Brand > Insights - Content Engagement Rate - Tile level export - PNG and CSV

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-51490
- **Priority:** Trivial (P5)
- **Description:** Ensure the export functionality of the Content Engagement Rate tile CSV.

## Preconditions
- User logged in as Hulu

## Steps
1. Click Brand in top nav and click Insights
2. Type and select 'Hulu' brand from the brand dropdown
3. Click the Graph Type dropdown in the Content Engagement Rate tile
4. Select 'Area' option
5. Click the Export drop-down and Select CSV
6. Click the Graph Type dropdown in the Content Engagement Rate tile
7. Select the 'Table' option
8. Click the Export drop-down and Select CSV
9. Click the Graph Type dropdown below the Content Engagement Rate and select Line Chart
10. Click Export Dropdown and select PNG

## Assertions
- A1 (step 2): Bar Chart, Export, and Save to Dashboard options displayed below Content Engagement Rate tile
- A2 (step 5): File Name format `Brand Name - Tab Name - Tile Name - YYYY-MM-DD(Start)-YYYY-MM-DD(End).csv`
- A3 (step 5): CSV columns Date, Brand Name, Channel, Content Engagement Rate
- A4 (step 5): CSV data matches tile data
- A5 (step 8): File Name same format as step 5
- A6 (step 8): CSV columns Brand Name, Channel, Content Engagement Rate (no Date — Table flat)
- A7 (step 8): CSV data matches tile data
- A8 (step 10): File Name `Brand Name - Tab Name - Chart Name -Line-YYYY-MM-DD-YYYY-MM-DD.png`
- A9 (step 10): Chart Title `Brand Name - Chart Name`
- A10 (step 10): Legends include Facebook, Twitter, Instagram, --Compared To
- A11 (step 10): Displaying date appears below legend
- A12 (step 10): X and Y axis labels match the page
