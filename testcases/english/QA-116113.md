# QA-116113 — Youtube Audience Tile level export PNG

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-116113
- **Priority:** Minor (P4)
- **Description:** Ensures PNG export functionality on YouTube Audience Tab.

## Preconditions
- User logged in as Disney Ad Sales

## Steps
1. Brand > Audience
2. Type and select 'Disney Channel' brand
3. Enable YouTube channel only
4. Export → PNG below 'Gender Breakdown'
5. Export → PNG below 'Age Breakdown'
6. Export → PNG below 'Demographics'

## Assertions (apply to all 3 PNGs)
- A1: File Name: `Brand Name - Tab Name - Chart Name - YYYY-MM-DD(Start)-YYYY-MM-DD(End).png`
- A2: ListenFirst name with logo displays on the Chart
- A3: Chart Title: "Brand Name - Chart Name" shows below the Logo
- A4: PNG export chart matches the Related Tile on Web Page
- A5: Tab name "Brand Audience" displays below the Chart
- A6: Displaying date (explorer) displays below Brand Audience
