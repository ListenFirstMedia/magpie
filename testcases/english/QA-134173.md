# QA-134173 — Settings > Custom Metric - Info View

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-134173
- **Priority:** (not retrieved; treat as Critical per typical Custom Metric tests)
- **Description:** Verify tooltip behavior for Settings > Custom Metric Page. Info View displays a persistent tooltip that dynamically updates based on hovered elements and shows correct header, description, and element mapping.

## Steps
1. Top Navigation → Settings
2. Click Custom Metrics
3. Hover on Metric column WITHOUT enabling Info mode
4. Click Info button
5. Observe tooltip without hovering any element
6. Inspect Custom Metrics page
7. Hover Metric column
8. Inspect Metric column
9. Hover Description column
10. Inspect Description column
11. Hover Created Date column
12. Inspect Created Date column
13. Hover Creator column
14. Inspect Creator column
15. Hover Formula column
16. Inspect Formula column
17. Click Info button (to dismiss)
18. Hover each column

## Assertions (inferred from spec description, not retrieved in full)
- Info tooltip appears only after Info mode enabled
- Tooltip persists and dynamically updates on column hover (Metric, Description, Created Date, Creator, Formula)
- Tooltip header + description match each column's purpose
- Disabling Info mode dismisses the tooltip
