# QA-96038 — Brand > Audience - Instagram - Followers: Gender Breakdown data test

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-96038
- **Priority:** Minor (P4)
- **Description:** This test case ensures the meter values are not summed and displays the last value in the export.

## Preconditions
- User logged in as Hulu

## Steps
1. Click Brand in the top nav and select Audience in the dropdown
2. Click the Brand dropdown, Type and select 'Hulu'
3. Open the Network tab on the page (Ctrl + shift + i)
4. Select the 'Instagram' channel only
5. In the network tab, type the "instagram.page.gender" datapoint in the filter box at the top of the left
6. In the filtered result, find the 'Gender Breakdown' fetch request as shown in the screenshot in this test case.
7. In the response section(Network tab), note the "instagram.page.followers_m" from the Men Followers data and Female Followers data
8. Click the Export dropdown in the Followers: Gender Breakdown tile
9. Select CSV from the list

## Assertions
- A1: Ensure the first value of 'Men Followers' in the exported data matches the 'instagram.page.followers_m' data point > data from the Gender Breakdown fetch request in the Network tab (content/analysis fetch request).
- A2: Ensure the first value of 'Women Followers' in the exported data matches the 'instagram.page.followers_m' data point > data from the Gender Breakdown fetch request in the Network tab (content/analysis fetch request). *(Note: spec text references followers_m for women too — likely a typo; should be followers_f.)*
