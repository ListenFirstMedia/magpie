# QA-121217 — Brand > Content - Instagram - Instagram Collaborator count - Export

- **Source:** https://listenfirstmedia.atlassian.net/browse/QA-121217
- **Priority:** Blocker
- **Description:** Ensures the functionality of the Instagram Collaborator count in the Brand > Content page.

## Preconditions
- User should be logged into Hulu

## Steps
1. Hover over the Brand and Select Content from the Top Nav
2. Click the brand dropdown and enter "Hulu" select "Hulu" from the list
3. Select the Instagram Channel only
4. Review the collaborator icon on the post
5. Hover over the collaborator icon
6. Change the view to 'Detail' View
7. Change the view to 'Table' View
8. Note the first post's collaborator count
9. Click the Export button and click ok button in the export modal
10. Review the downloaded CSV file

## Assertions
- A1 (step 5): Ensure the Instagram collaborator count is displayed. ex, icon(1)
- A2 (step 6): Ensure the count matches the tooltip collaborator count
- A3 (step 6): Ensure the Collaborated name should display
- A4 (step 7): Ensure the 'Collaborated' column displays the collaborator icon and the count
- A5 (step 10): Ensure the noted collaborator count matches the Instagram collaborator count
- A6 (step 10): Ensure the following headers are displayed in the export. Rank, Date, Day of Week, Time (PT), Channel, Brand, Author Link, Type, Post Link, Live, Publish Type, Paid, Sponsor Name, Sponsor Link, Instagram Collaborator Count, Instagram Collaborator Name, Instagram Collaborator Link, Text, Engagements, Reactions, Comments, Shares, Response Rate, Video Views
