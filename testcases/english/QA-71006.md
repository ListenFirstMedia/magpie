## Steps
1. Click Brand in the top nav and Click the Content tab.
2. Click the Brand dropdown and Type Michael Kors, select table view.
3. Click the data set dropdown and Select Facebook Only: Reactions.
4. Click the Export button.
5. Click the ok button in the export popup.
6. Click the OK button in the Select Data Set Export Request popup.
7. Open the corresponding Email.
8. Download the attached CSV export in the mail.
